## 验证

- 文档阶段：task.py validate、git diff --check，无需全量业务测试。
- 初始化：隔离 PostgreSQL 执行有序正式迁移，验证新库/已有库、重复初始化和管理员配置保留。
- 后端：go -C server test -p 32 定向用例，覆盖 RT/吨、箱型、无来源、共享箱/拆票、跨组织和精度边界。
- 前端：pnpm --dir web exec vitest run <受影响测试文件>，覆盖确认/取消/切换/迟到响应/手改/冻结/复制/补录。
- 修改文件 Biome、前端类型、git diff --check；提取公共能力时检查架构依赖。
- 最终 pnpm run check:fast：涉及迁移、契约和多个录费入口，需要全栈门禁；不固定执行生产构建。

## 风险

箱型同义码、计划/实际混用、共享箱重复计量、浮点精度和异步迟到结果为重点风险。不得自动覆盖管理员配置、已审核费用或公司默认费项。若映射或来源语义扩大设计范围，先回到规划。
