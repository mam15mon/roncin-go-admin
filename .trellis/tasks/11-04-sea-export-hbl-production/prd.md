# 海运出口 HBL 单证制作

## 目标与用户价值

业务人员从海运出口订单进入 HBL 制作，使用订单和真实 HBL 资料完成预览、打印与 PDF 导出，减少外部模板重复录入。

## 背景与证据

- 现有「海运单证」入口进入订单详情，没有独立制作及打印输出页面。
- 「导出单证 (POD)」实际打开放货凭证登记面板，不能制作 HBL。
- 已有真实 HBL 内容、独立版本及审核/改单机制，可复用收发通知人、货描、唛头、件重尺、条款和代理文字。
- 订单已有订舱号、共享航程和港口资料；正本份数、实际装船日、签发地/签发日、前程运输等尚无完整制单契约。
- 用户提供的 `HBL-RONCIN (2).pdf` 为北京公司单页 A4 模板；开发环境同时存在北京、成都公司，需区分模板适用主体。
- 代码、模板字段及公司盘点见 [现状研究](./research/current-state.md)；字体/输出技术验证见 [PDF 输出研究](./research/pdf-output.md)。

## 需求

### R1：入口与真实单证

- 海运出口订单详情提供「HBL 制作」，订单列表的海运单证入口也可进入，明确显示当前订单和 HBL 号码。
- 使用本票真实 HBL，不因打印创建占位 HBL 或静默转换直单模式。
- 「导出单证 (POD)」更名为「放货凭证 (POD)」，实际登记功能与 HBL 制作分开。
- 用户确认首期仅做 RONCIN 自签模板。以此次提供的北京抬头为本期版式，适用于北京公司自签 HBL；成都、客户、代理及其他主体明确提示本期无适用模板，不套用北京抬头。

### R2：模板与数据

- 大致参照用户 PDF 的主要区块和层级输出 A4 竖版，不要求逐像素复制；保留公司抬头、Logo、收发通知人、运输、箱货、签发区和固定条款。
- 自动带入同一 HBL 已保存正文及订单可用资料；手工维护内容优先，重新带入需明确操作，不随共享航程或订单刷新静默覆盖。
- 模板中的样例客户、货物、联系人、日期、ICN 不作为业务默认值，也不把含样例内容的 PDF 当打印底图。
- 常规资料单页；长地址、货描、箱号等自动续页，显示 HBL 号及页码，不静默截断、覆盖或缩成不可读文字。
- 用户已确认制作编辑保存回订单同一份真实 HBL，收发货人、货描等在订单和制作页回显一致，不另存一套打印稿。
- 补齐模板所需的正本份数、实际装船日、签发地/签发日、前程运输、联系方式与运输印字；可空保存，日期独立填写，不照抄样例或自动当作 ETD。
- 运输印字允许调整英文显示，不修改共享航程；实际箱信息来自本票实际装箱及共享箱分配，不用箱计划冒充实际箱。

### R3：版本与输出

- 草稿、正本、电放、副本使用同一版式，分别清楚显示 `DRAFT`、`ORIGINAL`、`SURRENDERED / TELEX RELEASE`、`NON-NEGOTIABLE COPY`，默认选择草稿。
- 预览、打印、PDF 内容一致，中文、英文、换行和业务数值显示完整。
- 用户明确订单审核锁主要用于利润核对，不作为制单输出前置条件：未审核也可选择草稿、正本、电放、副本进行预览、打印和 PDF 导出。
- 四种输出由操作人员选择；不新增审核后才能输出或按审核状态自动限制版本的流程。选择输出版本本身不更改 HBL 状态、放单方式或订单审核状态。
- PDF 以明确的已保存内容为基线，未保存编辑有提示；文件可直接下载，打印使用同一 PDF 的浏览器原生打印入口。

### R4：权限与编辑保护

- 复用组织范围、HBL 编辑及审核/改单约束，不绕开审核锁修改正式内容；锁定限制资料写入，不阻止按权限读取和输出已保存的内容。
- 制作中发现他人修改时保留输入并提示刷新，保存执行最终版本校验。
- 切换用户、公司或订单时关闭旧单预览并清理文件资源，不让旧请求覆盖新单；失败保留输入并可重试。
- 制作新增信息纳入原有 HBL 内容哈希、改单差异和不可变版本；普通订单保存不能丢资料，历史记录不能随当前制作修改变化。

## 验收标准

- [ ] AC1（R1）：北京公司自签 HBL 可由详情和列表进入；标题、HBL 号和数据属于当前订单，无 HBL/其他模板主体有明确反馈且不伪造记录。
- [ ] AC2（R2）：模板的抬头、信息区、货描区、签发区可识别，无样例业务数据残留。
- [ ] AC3（R2、R4）：制作修改保存到同一份 HBL，在订单和制作页回显一致；重新进入可继续，旧版本提交明确冲突，审核锁定时不能绕过原有修改流程。
- [ ] AC4（R3）：未审核和已审核订单均可选择四种输出，预览、打印、PDF 标识一致；输出不改变审核状态、放单方式或 HBL 状态。
- [ ] AC5（R2、R3）：中英文、长地址、多行货描及箱货信息完整，长内容正常续页，HBL 号/页码/版本标识可辨，下载与打印使用同一 PDF。
- [ ] AC6（R4）：无权限、跨公司、锁定、作废及换单等场景符合业务约束。
- [ ] AC7（R1）：放货凭证入口名称与实际功能一致，登记功能保持可用。
- [ ] AC8：定向验证及风险匹配的门禁通过，PDF 经实际渲染检查。
- [ ] AC9（R2、R4）：正本份数和签发/装船日期保存往返正确，普通保存不清空，历史快照不被当前印字修改影响。

## 本期不包含

- MBL、托书、发票、装箱单的独立制作。
- 通用拖拽模板设计器、多品牌模板平台。
- 成都、客户、代理或其他主体的 HBL 模板和制作。
- 承运人、银行、海关外部系统对接或电子签名服务。
- 重建现有审核、改单、作废和放货流程。
- 自动盖章、PDF 自动上传附件、导出文件台账和背面条款模板扩展。
