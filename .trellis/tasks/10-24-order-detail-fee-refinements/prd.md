# PRD：订单详情人员带入与状态跳转、费用科目精简、费用录入日期与汇率调整

## Goal

上线前打磨订单详情、订单状态与费用录入规则：内部人员由客户带入、订单状态可跳转补齐与一键完结、费用科目取消费用大类、费用日期改为不可变录入日期、汇率统一按 ETD 解析、财务凭独立权限可调整同币种订单费用汇率。

## Requirements

### 1. 内部人员：业务/客服不可手改，只能由客户带入

- 订单表单（新建与详情）中「业务人员」「客服人员」两个字段只读，不可手工选择或清空。
- 选择客户时自动带入客户档案上配置的业务/客服人员（现有带入逻辑保留）；更换客户时按新客户档案覆盖。
- 客户档案未配置这两个岗位时，创建订单与更换客户均被拒绝，提示先维护客户档案（两岗必填）。
- 新建模式下三岗均必填：操作人员手选，业务/客服由客户带入（服务端以覆盖后事实校验）。
- 服务端在订单创建/更新时以客户档案为准重算业务/客服两个角色，忽略请求中这两个角色的手工值（防 API 绕过）。

### 2. 订单状态：支持跳转补齐与一键完结

- 主流程节点（已订舱 → 已配舱 → 拖车已安排 → 已截单 → 报关已安排 → 已放单）允许点击任意**后续**节点直接跳转；被跳过的中间节点自动补齐完成，补齐记录的操作时间显示为跳转时的当前时间。
- 跳转时不对中间节点做空运数据完整性校验；目标节点仍执行现有校验（空运航班号、货物描述、签单状态等）。
- 在「未完结」状态下直接点击完结：主流程未完成时自动把全部节点补齐（全部激活，时间为当前时间）后再结案；结案既有的其它前置检查（无活动异常、无未建账费用、无待审补录）保持不变。
- 状态节点仍不允许回退。

### 3. 费用科目：取消费用大类

- 费用科目（fee_setting / fee_setting_template）不再挂「费用大类」，相关字段、接口字段、维护页输入、筛选与展示全部移除。
- 主数据中的「费用大类」类型及其数据一并下线。

### 4. 费用录入：发生日期改为不可变的录入日期

- 费用不再有可编辑的「发生日期」；界面展示「录入日期」，取费用创建时间，创建后不可变更。
- 批量修改接口中的发生日期维度删除；费用台账等按发生日期的筛选/排序改为按录入日期（创建时间）。
- 补录、更正等派生费用入口同步去掉发生日期输入。

### 5. 汇率按订单 ETD 解析，应收应付同规则

- 费用（应收与应付）折本币汇率统一按**订单 ETD** 所在自然周的汇率解析，不再按费用发生日期解析；汇率快照日期记录 ETD 所在周的基准日。
- 汇率双轨（应收 ar_rate 现汇卖出价 / 应付 ap_rate 现汇买入价）保留；「应收应付都一样」指两者都按 ETD 取值。
- 订单未填写 ETD 时，费用汇率解析失败并明确提示先填写 ETD。

### 6. 财务调整费用汇率的独立权限（限应收应付同币种）

- 新增独立权限码（独立于「编辑汇率」），持有人为财务。
- 持该权限的用户在**订单内应收费用币种集合与应付费用币种集合相同且均非空**时，可在费用录入/编辑中手工指定汇率（MANUAL 覆盖）；不满足条件时拒绝并提示。
- 原「编辑汇率」权限不再授予业务单据手工汇率入口。

## Acceptance Criteria

- [ ] 订单表单中业务/客服不可编辑；选择客户后自动填充；客户缺岗可为空保存；API 提交伪造的业务/客服值被服务端覆盖为客户档案值。
- [ ] 从任一主流程节点可直接点击后续任意节点，中间节点全部补齐且各节点时间轴显示当前时间；空运跳转仅校验目标节点数据。
- [ ] 未完结订单直接点完结即完成结案，主流程节点全部激活。
- [ ] 费用科目维护/选择/筛选界面与接口不再出现费用大类；费用大类主数据与迁移清理完成。
- [ ] 费用表单无发生日期输入；列表与台账展示录入日期（创建时间）且编辑不可更改；批量修改仅剩结算单位维度。
- [ ] 应付/应收费用汇率解析请求不再携带日期，服务端按订单 ETD 所在周解析；ETD 为空时报错提示先填 ETD；费用快照汇率日期=ETD 周基准日。
- [ ] 新权限码生效：无权限用户看不到手工汇率入口；有权限且订单应收应付同币种时可覆盖，币种不一致时被拒。
- [ ] 契约/权限/前端生成物全部重新生成，定向测试通过，`pnpm run check:fast` 通过。

## 假设记录（澄清问题未获答复，按推荐方案执行，如与预期不符请在 review 时指出）

1. 汇率「应收应付都一样」＝解析日期统一为 ETD，双轨 ar/ap 保留。
2. 「同币种」＝订单内应收费用币种集合 == 应付费用币种集合（均非空）。
3. ~~客户缺岗 → 允许为空提交~~（已按用户后续反馈修正：两岗必填，客户缺岗拒绝创建/换客户。）
4. ETD 缺失 → 汇率解析报错，提示先填 ETD。

## 非目标

- 不改动汇率表结构、牌价同步流程与周匹配规则。
- 不做历史数据兼容迁移之外的回填（无生产历史契约，一次性切换）。
- 不改动费用审核锁、建账、核销等既有链路行为（除日期口径替换）。
