# 整套财务模块优化与报表建设

## 目标与阶段

减少订单费用逐行操作，明确汇率、税率及利润口径，打通费用、账单、发票、收付核销、提成与财务报表全流程。用户已明确将参考材料中的整套财务模块纳入本期。
本次用户要求创建 Trellis 任务；当前为需求规划，尚未批准实施，不修改产品代码。

## 需求与验收标准

| 编号 | 需求 | 可观察验收标准 |
| --- | --- | --- |
| R1 | 费用录入取汇率：出口 CASE 按 ETD，进口 CASE 按 ETA | 应收、应付均按订单进出口方向采用对应日期查询汇率：出口 ETD、进口 ETA，再分别取应收汇率与应付汇率；覆盖不同日期汇率不同的场景，不能默认按录入当天取值。不加入日期优先级配置；缺日期显式报错，不默认回退。新增费用按当前出口 ETD／进口 ETA 取值；已保存费用按财务状态决定自动更新：仅使用系统汇率且未建账，或使用系统汇率且已建账但无有效发票、核销、对冲关联时，自动更新费用汇率日期及汇率；财务手工指定的汇率以及已有财务动作的费用保留原快照，财务授权显式修改除外。ETD／ETA 变更保存时立即更新符合条件的费用，无需再次进入费用页或点击整表保存；仅在输入框修改但尚未保存时不写费用。需要更新的费用缺少目标周汇率时，拒绝本次日期保存，日期与费用更新全部成功或全部失败，并提示补齐汇率。 |
| R2 | 应收、应付始终打开编辑，各自标题右侧提供整表保存，取消逐行编辑与保存 | 在当前有权编辑且业务允许的费用上直接输入，分别保存应收表和应付表；校验失败及并发冲突保留输入，不得因常开编辑绕过锁定、已建账等限制。应收、应付独立提交，各自整表全部成功或全部失败；保存一侧不提交、清空或覆盖另一侧未保存输入。 |
| R3 | 税率可以按权限更改 | 财务权限分组新增准确名称「订单费用税率更改权限」；有权人员可修改允许编辑费用的税率，无权人员不能修改，服务端也拒绝越权请求；权限源与生成物同步更新。 |
| R4 | 应收、应付、毛利看板展示含税和不含税两种口径 | 应收、应付、毛利各自卡片内同时展示「含税／不含税」两组金额，无需切换；明确标注且与费用税额一致，避免不同币种未经折算相加。 |
| R5 | 重新规划费用录入表头列宽 | 应收、应付统一规划列宽，名称、金额、税率与操作可读可操作；窄屏允许合理横向滚动，容器遵循全宽规范。具体列宽在设计阶段形成可审阅方案。 |
| R6 | 排查费用明细台账主单号不显示 | 对有主单关联的订单显示正确主单号，无主单时明确为空；沿来源、服务端投影、DTO 映射与列渲染定位，覆盖相关海运/空运路径。尚未确定根因。 |
| R7 | 筛选区提供类似表头的设置，用户自主增加或删除筛选项 | 用户可在设置中选择显示的筛选字段；这里的增加/删除指筛选项展示配置，不删除业务数据。移除筛选项时清除该字段值及生效条件并刷新列表；普通展开/收起保留条件。偏好保存范围及适用页面待确认。 |
| R8 | 费用批量转账单页面的结算账户支持快速添加 | 参考订单客户快速添加交互，在建账过程中创建结算账户并可选用；关联正确结算对象与当前公司，遵循已有账户创建权限。不得丢失建账配置。 |
| R9 | 账单无需人工确认；录入发票号时锁定费用明细 | 创建账单后直接进入对账流程，无需点击确认；不存在有效发票登记、付款核销或对冲关联时，允许有权限人员增加、移除账单费用明细并重算金额；成功保存发票号、发生付款核销或对冲，任一条件满足后整张账单禁止增删费用，部分开票、部分核销或部分对冲也不能绕过。触发业务操作与锁定须原子完成，前后端统一拦截，并发中的费用调整不得越过锁定。添加仅选择未建账、与账单同币种且同一结算客户/供应商的费用；同时遵循同公司、同收付方向的现有约束。移除仅解除账单关联，不修改或删除原始订单费用。候选过滤与服务端提交校验必须一致，提交时复核费用未被其他账单占用。有效发票、核销和对冲关联全部解除后恢复费用增删；仍有任一有效关联则保持锁定，保留全部历史操作记录。 |
| R10 | 调整账单列表状态并在账单页面录入发票号 | 用户已确认采用「开票进度＋核销进度」分别展示，允许同时表达部分开票与部分核销，不强行合并为五个互斥状态；综合「已完成」判定仍待确认；账单内支持分次录入多张发票，每张记录发票号、日期、本次对应账单的金额，按累计金额计算开票进度，沿用发票权限与业务关联；第一张发票成功保存即锁定整张账单费用明细，仍允许补录后续发票。不能只改文案造成状态与真实业务不符。 |

| R11 | 完善批量建账交互 | 固定按币种分组，按参考完善税率/订单拆分；创建时可选择登记发票、核销，仍允许不登记发票先核销；组合保存与批量失败规则待设计。 |
| R12 | 完善发票记录与批量登记 | 保留独立发票列表、详情、筛选与导出；支持账单内分次登记及批量入口，关联金额可追溯；跨账单分配、更正、撤销与类型规则待收敛，不默认对接在线税务系统。 |
| R13 | 完善收付、核销与对冲 | 保留独立列表及详情，完善登记、部分/多次核销、预收付使用、批量核销与反向操作；预收付款不足时补录差额流水，与核销最终原子提交，取消弹窗不生成流水；金额与余额在账单、费用和收付记录间一致；跨币种、手续费、损益及回退规则以确认契约验收。 |
| R14 | 完善提成管理 | 按订单、人员筛选并选择规则，覆盖含税/不含税、利润区间/阶梯、记录查询与导出；先核对现有已实现利润计提与参考规则差异，再确认算法，保护已发事实。 |
| R15 | 新增或补齐四类财务报表 | 利润分析图、利润报表、实际收付款报表、账龄表均纳入；支持对应筛选维度、汇总和导出；公式、日期、账龄分段、历史截止口径须明确，图表与列表可对账。 |

## 已确认决策

- 用户确认财务手工指定的汇率保留：航期变化不覆盖手工值及其原取值快照，即使费用未建账或财务尚无动作；自动更新和目标周缺汇率校验仅针对符合条件的系统汇率费用。

- 用户确认目标周汇率缺失时阻止 ETD／ETA 保存：本次日期与需联动费用原子更新，不允许日期成功但费用部分保留旧率；提示补齐缺失汇率。

- 用户确认「立即更新」：在 ETD／ETA 变更保存时立即更新满足财务状态条件的费用，不等待费用整表保存，不依赖费用页面打开。

- 用户确认移除筛选项时清除其筛选值并刷新列表，普通收起筛选区保留条件；重新添加已移除字段不恢复之前清除的值。

- 用户确认应收、应付、毛利卡片同时展示含税与不含税两组金额，不使用切换方式隐藏另一种口径。

- 用户确认应收、应付独立保存：各自整表原子提交，任一行校验失败或并发冲突则该表不产生部分保存，保留输入；另一侧未保存草稿不受本次保存刷新影响。

- 用户最新修订汇率规则：不增加日期优先级配置；使用系统汇率且未建账或已建账且财务尚无动作时允许自动更新；手工汇率及其他状态保留原费用汇率，财务显式手改除外。这替代此前已保存费用一律保留原日期/汇率的决定；不恢复已退役的独立费用发生日期字段。

- 用户确认差额收付款与本次核销在最终保存时一起提交，全部成功或全部失败；取消弹窗不产生新流水，不提前保留差额流水。

- 用户明确回复「纳入」：海管家参考中整套财务模块进入本期；按六个子任务组织，不再将提成及四类报表排到后续范围。原 R1–R10 与已确认规则继续有效。

- 2026-11-13：用户确认一张账单可分次登记多张发票，记录号码、日期、本次对应账单金额，累计计算开票进度；首次登记后禁止增删费用，但可以继续登记后续发票。

- 2026-11-13：用户确认应收、应付统一使用「出口按 ETD、进口按 ETA」的日期基准，分别取应收/应付方向汇率。

## 账单费用维护的重点验收场景

- 添加候选只显示符合账单公司、币种、收付方向与结算对象的未建账费用，不能仅凭相同客户/供应商名称匹配。
- 手工篡改请求提交不同币种、不同结算对象、跨公司或已建账费用时，服务端拒绝；两张账单并发抢占同一费用时，不得重复关联。
- 从账单移除费用后，原始订单费用及其金额、税率、结算对象保持不变；账单关联释放、金额与费用条数重算一致，符合其他业务条件时该费用可重新建账。

## 开票与锁定的重点验收场景

- 两张有效发票只作废一张，或发票全部作废但仍有有效核销/对冲时，禁止增删费用；最后一项有效关联解除后恢复费用增删，仍执行账单有效性、公司范围与操作权限等检查。
- 全部关联解除不删除历史发票、核销、对冲及审计记录，也不代表解除订单业务审核锁；账单移除仍不触碰原始费用。
- 最后一项撤销失败时不能提前解锁；撤销与新登记/核销/对冲并发时，服务端按最新有效关联校验，不允许因旧页面显示可编辑而绕过锁定。

- 以同币种、需全额开票的正常账单 10,000.00 为例：首次登记 3,000.00 后显示部分开票，费用明细立即禁止增删；补录另一张 7,000.00 后累计为 10,000.00，显示已开票。
- 首张发票保存失败不视为录入成功，不得留下孤立的发票关联或锁定结果；保存成功后其他用户持有旧页面发起增删，服务端仍拒绝。
- 未录发票但已有部分付款核销或对冲时，同样禁止增删费用。开票与核销两项进度各自真实显示，互不覆盖。
- 费用明细已锁定不阻止授权人员补录后续发票；两人并发登记时按服务端最新金额与版本校验，避免重复累计或丢失登记。
