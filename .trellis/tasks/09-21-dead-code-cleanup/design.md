# 清理设计

以路由与生产入口为根检查前端 import/export 可达性，兼顾动态 import、public 资源和构建配置。后端按包引用、接口实现、Wire/反射/生成工具和测试引用核对。先形成确认删除清单，再分别清理前后端；不把测试专用功能误当垃圾。

依赖使用 pnpm 正式移除并更新锁文件；Go 使用 tidy diff 审阅后整理，不升级无关版本。删除接口链同时更新测试桩，仅移除死方法专属测试，不削弱仍在用功能的测试。

风险是隐式入口与构建依赖被误删，因此依赖和迁移遗留必须经过生产构建验证。Sentry 和回填工具明确延期，复核发现报告错误则保留并记录。回滚以分组 Git 提交为边界。
