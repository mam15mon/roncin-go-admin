# 全仓死代码与未使用依赖清理

## 目标
复核用户提供的 GLM 扫描报告，仅清理确认无生产用途的代码与依赖，保持当前业务和构建行为。

## 背景与证据
用户在 2026-09-21 同意创建任务。初查工作区干净；部分 Go 私有函数仅定义无调用，部分接口死链仍有测试引用；五个前端依赖在源码、配置、测试、脚本中未检出直接引用。Sentry 初始化未接入 main.tsx，但 requestErrorConfig.ts 和上传脚本仍使用 Sentry，不能视为整套无用代码。

## 范围
- 复核并清理报告第一类中的前端迁移遗留、孤儿组件、无消费导出与样式。
- 复核并清理确定无调用的 Go 符号，接口死链同步处理实现与测试桩。
- 移除确认未使用的五个前端直接依赖，同步 pnpm 锁文件；审阅 go mod tidy 差异并仅保留必要模块整理。
- 每项删除必须记录入口、引用或接口实现核查证据，不能仅凭文本命中数量判死。

## 不在本期
保留 Sentry 功能及配置，不接线也不删除；保留回填命令和有意测试钩子；仅测试使用的生产符号保留。重复实现和过度导出不批量重构。忽略的本地构建缓存不作为交付删除项。不删除数据、不改业务契约、不手改生成物、不升级无关依赖。

## 验收
- 删除清单逐项有复核证据，不包含真实路由、动态加载入口、生成源或运行依赖。
- 所有调用方、接口实现、导出索引及受影响测试同步一致。
- 定向检查、git diff --check、check:fast 与生产构建通过；未运行项目明确记录原因。
- 未引入业务变化、兼容分支或规则豁免，按可验证分组提交。
