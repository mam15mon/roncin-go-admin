# 空运 MAWB 同号主单判断对齐海运

## Goal

用户反馈海运的主单号判断比空运 MAWB 好用，并明确要求两边**统一**。目标：
空运（AE/AI）新建订单时，业务人员只填主运单号，系统自动核对同号主单并就地
给出结论（新建 / 加入已有主单 / 不能使用），在保存前拦住未处理的情况，
不再要求先选「新建/关联」，也不再在保存时被后端 `AIR_WAYBILL_EXISTS` 退回。

## 背景

### 海运范本

`templates/components/sea/useSeaMasterBillCandidate.ts`、`SeaTransportSection.tsx`：
无前置选择；输入主单号后 300ms 防抖精确核对；命中即就地卡片「已找到主单 X，
已有 N 票，本票保存后将加入该主单，共 N+1 票」并展示共用资料；本票空字段自动
带入，非空差异逐项列出并提供「采用主单航程」；无冲突自动确认关联；保存前拦截
核对中、查询失败、直单占用、模式不符、资料冲突、未确认关联。

### 空运现状

`templates/components/air/AirMasterFields.tsx`：

- 需先选「新建主单 / 明确关联已有主单」（`airMasterMode`），关联走「选择共享主单」
  关键字下拉。
- 新建模式下 `AirMasterCandidateHint` 只显示一条 warning 与「选择此主单」按钮；
  无防抖、无保存前拦截，忽略后保存被后端拒绝
  （`server/internal/biz/air_export.go:23` `ErrAirWaybillExists`）。
- 关联时直接用主单资料覆盖本票已填的主单字段，不提示差异，也不提示加入后票数。
- 主单工作台可经 URL `masterId`（及 `documentMode`）预选主单建票。

### 空运领域约束（不照搬海运）

- 主单身份 = 组织 + 业务类型 + 11 位 MAWB（唯一索引），航空公司不参与身份。
- 一张主单只有一份共同运输资料（航空公司、航班、起运/目的机场、班期、截单/报关、
  申报件重尺、主单状态、主单备注），无海运多航程选择；关联后共同资料以主单为准，
  本票不保存副本。
- 主单可关联性由后端给出：`canAttach`、`attachBlockedReason`、`documentMode`、
  `memberCount`；现有 `ListAirMasterWaybills` 对 MAWB 做包含匹配
  （`server/internal/data/air_export.go:295`），完整 11 位号只会命中自身，
  前端再按完全相等筛选即为精确核对。

## Requirements

- R1 取消「主单关联方式」单选与「选择共享主单」下拉；新建页主单小节只保留
  一个主运单号输入入口（连同航空公司、航班、机场等主单字段）。
- R2 主运单号通过格式与模 7 校验后，防抖 300ms 自动核对同号主单（AE/AI 按各自
  业务类型）；号码不完整或格式错误时不核对。
- R3 未命中：按新建主单处理，主单字段照常可编辑，提示「未找到同号主单，保存后
  将新建主单」。
- R4 命中且可关联、单证模式一致：就地卡片显示「已找到主单 X · 航空公司 · 已有 N 票，
  本票保存后将加入该主单，共 N+1 票」及主单共同资料摘要；本票空的主单字段自动
  带入主单值；无差异时自动确认关联，主单字段转为只读（以主单为准）。
- R5 命中但本票已填的主单字段与主单不同：逐项列出「字段：本票 X；主单 Y」，
  提供「采用主单资料」按钮，采用后确认关联；采用前不能保存。
- R6 命中但单证模式不符（如主单为 HOUSE、本票选 DIRECT）：提示原因并提供
  「切换为主单模式」按钮；切换前不能保存。
- R7 命中但不可关联（`canAttach=false`）：显示后端原因（如直单主单已有操作票、
  成员已锁定或终止），提示更换主单号；不能保存。
- R8 改动主运单号即解除上一次核对结论：取消关联、恢复字段可编辑，保留用户已填值。
- R9 保存前校验（挂在主运单号字段）：核对中 →「正在核对已有主单，请稍候」；
  查询失败 → 显示失败并要求重试；R5/R6/R7 未处理 → 对应中文提示；保存时仍由
  后端版本号做最终校验。
- R10 主单工作台带 `masterId` 进入新建页时，自动填入该主单号并直接处于「已关联」状态，
  效果与 R4 一致。
- R11 提交载荷契约不变：关联时发送 `masterWaybillId` + `expectedMasterVersion`，
  新建时发送 `master`；`airExportFormAdapter` 的对外行为不变。
- R12 详情页行为不变（共享主单摘要 + 运输维护入口），不在详情页提供改号关联。

## Acceptance Criteria

- [ ] 新建页不再出现「主单关联方式」与「选择共享主单」。
- [ ] 输入未被使用的有效 MAWB：显示将新建主单，保存成功并新建主单。
- [ ] 输入已存在且可关联的 MAWB、本票未填其他主单字段：自动带入并显示「共 N+1 票」，
      主单字段只读，保存后本票加入该主单（载荷含 `masterWaybillId` 与版本，无 `master`）。
- [ ] 本票已填航班等与主单不同：列出差异，点「采用主单资料」前保存被拦并提示，采用后可保存。
- [ ] 单证模式不符、主单不可关联、核对中、核对失败四种情况保存均被前端拦下并给出中文提示。
- [ ] 改号后关联解除、字段恢复可编辑且保留已填值；改回原号重新命中。
- [ ] 从主单工作台带 `masterId` 进入新建页直接处于已关联状态并可保存。
- [ ] AE 与 AI 各自只命中本业务类型主单。
- [ ] 表单适配器测试不改即通过；受影响的空运模板测试按新交互更新并通过；
      修改文件 Biome、`pnpm --dir web tsc` 通过。
- [ ] 浏览器实测上述主要路径（AE 至少覆盖新建、加入、差异采用、不可关联）。

## Out of Scope

- 后端与 Proto 改动（不新增专用核对接口）。
- 分单号（HAWB）在主单内重复的前端预检，保存时仍由后端拦截。
- 详情页改号/改挂主单。
- 主单工作台与运输维护弹窗的交互调整。
