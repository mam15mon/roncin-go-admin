# 统一筛选设置与布局能力实施计划

## 启动条件

前两个子任务完成生成 API 与前端 display-preferences Provider 后实施；先在既有财务区域验证，再交付全站接入。

须先取得对最新父任务完整方案的审阅批准，再 task.py start 本子任务。

## 步骤

1. 实现中立字段布局与面板，随后补纯解析和交互验证；不得先写测试驱动实现。
2. 完成 grid/bar/独立表单/官方Pro搜索适配与查询清理，先让现有财务筛选消费全部维度。
3. 定向验证排序、宽度、折叠、复合清值、未提交输入、失败重试和两身份隔离；必要重型组件用例按功能拆分。
4. 执行受影响 vitest、Biome、tsc、check:architecture 和 git diff --check，提交公共能力；更新能力导航与筛选规范。
5. 交付稳定公共签名给全站接入子任务，禁止继续由各页面另造设置模型。

## 完成门

验收结果与未验证限制写入本子任务 research/，所有权和生成物清晰，独立 trellis-check 无阻塞后交付父任务。父最终门禁见[集成计划](../11-16-global-filter-settings/implement.md)。
