
必须确认 RONCIN_INTEGRATION_DATABASE_SOURCE 已配置且真实库用例无 SKIP，使用独立测试 schema 和正式迁移，不调用 Schema.Create，不对业务库运行 bootstrap 作为测试。新增授权和并发为高风险写入，子任务完成运行 check:fast；不因普通代码变更额外执行生产构建。

## 测试矩阵

- [ ] 空账号表、已有公司情况下首次建立管理员；每个启用公司只有一条成员及管理员绑定。
- [ ] 已有管理员重复执行两次，不改密码哈希/姓名，不增重复记录，不清普通员工或其他角色绑定。
- [ ] 非初始的系统管理员不会被自动加入新公司。
- [ ] 自建公司与默认种子行为一致；部门/组无重复成员。
- [ ] 账号/系统工作台停用无授权写入；公司/角色/成员停用明确跳过，人工恢复后重跑补齐。
- [ ] 无初始、多初始、普通同名、配置身份冲突均明确失败。
- [ ] 事务后段失败/审计失败回滚；并发创建公司与补齐最终成员完整且无重复。
- [ ] 公司角色无系统专属权限，切换仍需真实成员关系。

验证记录需区分“角色存在”“成员存在”“绑定存在”，不能仅断言角色数就认为管理员可进入。以 ResolvePrincipal/工作台候选验证实际进入结果。
