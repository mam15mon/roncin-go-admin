# 提成管理增强（CNY 快照 / 导出 / 归属日期）

## Goal

按 [docs/plans/提成管理增强计划.md](../../../../docs/plans/提成管理增强计划.md)
落地三项增强：导出提成、CNY 折算展示、提成归属日期。该计划文档是本任务组的
唯一真相源，口径冲突时以它为准。

## 前置条件（阶段 0，进入任何子任务实现前必须完成）

以下口径来自计划 §4.2，需用户逐项确认冻结：

1. **汇率来源与方向**（§4.2.1）：统一 `WRITE_OFF` 汇率类型 + `RECEIVABLE`
   方向；汇率日期用 `verification.exchange_rate_date`；本位币非 CNY 时经
   `CNY → base` 核销汇率倒数派生（DERIVED）；decimal 计算，禁浮点。
2. **汇率缺失语义**（§4.2.2）：预览与生成均强制解析，缺失即报错阻止生成。
3. **调整单口径**（§4.2.3）：调整继承主单汇率，CNY 调整/有效金额动态汇总不落库。
4. **折算范围**（§4.2.4）：第一版仅主提成单三组金额，明细行不做 CNY。
5. **月份筛选边界**（§4.2.5）：`YYYY-MM-DD` 字符串、含边界、默认排序稳定。
6. **导出上限与字段**（§4.2.6）：同步导出上限 10000 行，超限拒绝不截断。
7. **存量数据前提**（§4.2.7）：确认生产无历史提成记录；有则暂停另定回填方案。

另需：用非 CNY 本币数据验证倒数精度与 `numeric(18,8)` 精度；核对 `Resolve`
在 CNY→本位币方向的 rateType 传参。

## 跨子任务验收（对应计划 §13 完成定义）

- [ ] 生成草稿包含完整 CNY 快照与归属日期；确认、支付不改变这些字段。

      导出有审计记录。
- [ ] 迁移链、后端测试、前端测试、类型检查与构建全部通过。
