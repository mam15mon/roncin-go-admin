# 权限分类与查找体验优化

## 目标与用户价值

管理员按业务模块、功能名称和具体操作快速找到权限，理解权限归属；角色授权与权限字典使用一致的分类口径，减少逐条翻找。

用户先询问权限是否自动分类，希望像钉钉一样方便查找；在说明现有机制并建议优化后，用户于 2026-10-16 回复「是的」，批准创建本任务。本文件为待用户审阅的实施范围，任务保持 planning。

## 已确认事实与约束

- `server/internal/access/manifest.go:189` 起统一登记权限名称、分组路径与依赖。分类由开发者声明，经迁移同步后供前端消费，页面自动组织展示。
- `web/src/pages/admin/components/roles/permissionMatrix.ts:65` 起已有模块排序及按分组路径生成资源模型；同文件 `filterResources` 已支持路径、名称、权限码及说明检索。
- `web/src/pages/admin/components/roles/RoleFormModal.tsx` 已支持模块导航、业务线筛选、全局搜索与批量选择，搜索命中具体操作时会自动展开。
- `web/src/pages/admin/components/roles/components/PermissionResourceRow.tsx:81` 目前显示业务线与资源名，跨模块搜索时缺少完整归属路径。
- `web/src/pages/admin/permissions.tsx` 的权限字典当前为无搜索栏的平铺表格，已有业务分组列。
- 权限勾选联动统一消费后端 requires；搜索或切换分类不能改变已选权限及授权含义。

## 本期需求

- R1：权限字典可按业务模块筛选，并通过关键词匹配功能名称、权限码、完整分组路径和说明；筛选项从接口返回的分组生成，与角色配置使用同一分类来源。
- R2：角色配置在全局浏览和搜索结果中展示完整业务归属，如「费用管理 → 账单」，具体权限仍显示其操作名称，避免同名功能混淆。
- R3：保留现有模块导航与细分业务线操作；清除搜索或分类条件后可恢复列表，空结果有明确提示。
- R4：角色配置文案采用业务语言，去掉现有「华为云 IAM 策略模式」等实现或竞品名称；保留必要的权限名称和说明。
- R5：新增权限正确登记分组并完成正式同步后，两个入口自动展示，管理员无需另行维护前端分类表。

## 验收标准

- AC1（R1、R5）：权限字典按接口内模块形成筛选候选；选择「费用管理」后仅显示该模块权限，后续新增模块可自然出现。
- AC2（R1、R3）：搜索「账单」、具体权限码或说明内关键词可定位对应权限；模块与关键词组合生效，清除后恢复，零匹配时显示空态。
- AC3（R2）：角色配置全局搜索所得资源显示完整模块/业务线/功能路径，具体操作名称可见。
- AC4（R3）：搜索、清除及切换模块均不改变当前已选权限；勾选操作继续自动补齐依赖，取消基础权限继续级联取消依赖项。
- AC5（R4）：角色配置标题和查找提示使用业务中文，界面无华为云/IAM 模式描述。
- AC6：实现后补充必要的筛选与选择保留回归验证，运行受影响测试、修改文件 Biome、类型检查及风险匹配的前端最终门禁；提交前通过 git diff --check。

## 范围外与延期项

- 本期沿用现有后端分组，暂不重新命名或迁移所有权限分类，也不改变菜单或路由结构。
- 不调整权限码、授权依赖、数据范围、角色模板或默认授予规则，不扩展为自动识别分类或自动分配员工权限。
- 不引入新的权限平台、数据库变更或钉钉权限集成，不做钉钉界面的完整复刻。
- 拼音、同义词、收藏或最近使用检索不进入本期。
