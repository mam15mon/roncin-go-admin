# 全局表格自定义冻结与全量铺排排序

## 目标与用户价值

一次看到全部可配置字段并跨行跨列拖动排序，无需在窄列表内滚动寻找目标；支持同时冻结多个指定字段。

## 背景与已确认事实

- 用户已同意创建任务和规划，尚待最终方案批准后实施。
- 用户明确要求「给所有的都排序，分成多列，我好方便拖动，我不希望我还需要去滚动容器」，布局交由实现方判断，不固定三列或三排。
- 当前入口为 Popover（`web/src/components/ui/column-settings/ColumnSettingsEntry.tsx`），Panel 宽 300px，列表最大高度 420px（`ColumnSettingsPanel.tsx`），字段多时需要容器内滚动。
- 公共类型 `types.ts`、冻结函数 `freeze.ts`、偏好 `preference.ts` 使用 first/last 开关，无法冻结多个自选字段。
- 普通表格消费 `useColumnSettings`；订单费用独立消费 `ColumnSettingsEntry` 和 `feeColumnPreference.ts`，有 19 个普通字段和末尾操作列，应收/应付共享设置。

## 需求

### R1 全量铺排与清晰序号

- 齿轮打开接近全屏的列设置弹窗，充分使用视口；根据宽高和字段数量选择列数，不固定三列。
- 常用桌面视口一次呈现全部可配置字段，移除原先 420px 高的内部滚动列表，不用分页、折叠或虚拟列表隐藏远处目标。
- 从左到右、从上到下排列，显示连续序号和中文列名，并说明阅读顺序。序号随完整顺序变化，搜索结果保留完整序号。
- 桌面基准为 1366×768、1440×900、1920×1080，以订单费用实际字段和 40 字段集合验证全部可见。窄屏和极端字段数量受物理空间限制时保证全部字段可访问，不承诺任意视口、任意数量均无滚动。

### R2 直接拖动与精确定位

- 可排序字段支持跨行跨列拖动，手柄清晰、目标插入位置明确；松手后更新完整顺序及编号，取消拖动不保存悬停状态。
- 提供直接指定目标序号的精确移位入口，方便远距离移动和键盘用户；控件操作不误触拖动。
- 保留显隐、全选、必显约束、搜索及恢复默认；搜索期间不拖动排序，避免把筛选后位置当作完整序号。

### R3 自定义多列冻结与最终顺序

- 普通字段逐列选择「左侧冻结 / 不冻结 / 右侧冻结」，左右均可多列，选择绑定字段身份。
- 表格最终按「左侧冻结 → 不冻结 → 右侧冻结」呈现，各区内部可排序；面板使用相同最终顺序和连续编号。修改冻结时移入对应区域，跨区拖动相应改变冻结状态，面板与表格顺序始终一致。
- 操作、选择、展开、序号等结构列保留必要锚点和不可隐藏约束；末尾操作列额外提供冻结选择，普通业务字段不冒充结构列。
- 隐藏再显示字段保留冻结选择，搜索不改变冻结结果；恢复默认同时恢复顺序、显隐及业务声明的默认冻结字段。

### R4 全局一致性与偏好

- Table、ProTable、EditableProTable 和订单费用专有链路同步更新，复用同一冻结实现。
- 设置即时生效并自动保存，关闭仅关闭面板；按用户、组织、表格隔离，订单费用应收/应付共享。
- 不兼容旧首尾冻结语义，不增加旧开关转换层；一次同步仓库消费者和测试。合法显隐/顺序继续按现有规则解析，旧冻结开关不再具有含义。
- 存储失败明确提示且保留当前效果；编辑中禁用入口、关闭已打开面板，关闭后不得继续写偏好。
- 保留表格分页、请求、选择、编辑输入、列宽；窄容器临时解冻由 Responsive 层负责，不回写偏好。

## 验收标准

- AC1（R1）：三种桌面基准下，费用实际字段和 40 字段集合全部可见，无需滚动设置列表，名称和连续编号可辨。
- AC2（R2）：末尾普通字段拖到第一位置、跨网格行拖动、指定目标序号均得到可预测顺序；取消拖动不改配置，勾选/冻结控件不误拖。
- AC3（R3）：两个业务字段左冻结，一个右冻结，横向滚动定位正确；面板编号与表格一致，跨区域移动按提示改变冻结。
- AC4（R3/R4）：隐藏/恢复、重挂载、恢复默认、新增/未知字段解析保持合法状态；必显、结构锚点和权限裁剪正确。
- AC5（R4）：公共表格和费用专有链路均验证；应收/应付共享，账号/组织隔离，存储失败提示，编辑中禁用。
- AC6（R4）：设置不重挂表格，不额外请求，不清空分页、选择、列宽、编辑；窄屏可访问全部字段，窄→宽恢复冻结。

## 范围外与延期

- 不调整后端、数据库、权限，不新增服务端偏好接口。
- 不修改列宽持久化、全站配色，不建设通用拖拽平台。
- 不承诺手机屏幕无滚动展示任意数量字段。
