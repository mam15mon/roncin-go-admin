# SE 新建页 MBL 录入布局设计

## 场景与边界
用户按船公司 MBL 集中录入完整订单资料。仅海运出口新建页调整；详情页继续原有分节和单证页签。
布局入口位于 `web/src/pages/orders/templates/sea-template.tsx`，字段所有权位于 sea 各分节组件。
当前工作区已有其他任务未提交修改，实施基于工作区快照 `/tmp/se-mbl-layout-baseline`，最终提交仅本轮差异。

## 组件与数据流
- 复用已有客户/危险品/船公司/箱型/主单字段组件；将现有基础与运输字段按职责拆为可复用组，再组合新建分节，避免复制联动与校验。
- 新建专用组合由 sea-template 选择；不向通用订单页注入海运分支。
- 单证状态管理继续单一 SeaDocumentSectionComponent 所有，必要时使用插槽或布局参数把新建主单/分单连续展示，禁止多实例状态分叉。
- 同一个 ProForm/Form store，字段 name 与转换器不变。委托字段只在主单处挂载一次，HBL 只录自身实际字段；详情保留现有行为。
- 补充区折叠须保留字段注册，校验失败能展开后定位；若现有模板不能安全支持则局部实现，不推广新的全局表单平台。
- 240px 文本域不变，件重尺使用分组网格；不新加全局样式覆盖。

## 风险与验证
重点验证 HOUSE/DIRECT 切换、多个同名 Form.Item、隐藏必填字段、客户/危险品联动、详情布局和保存权限未变。
浏览器以现有开发服务验收新建页和常见桌面宽度，只进行本地 UI 填写及拦截提交，不创建无关业务数据。
