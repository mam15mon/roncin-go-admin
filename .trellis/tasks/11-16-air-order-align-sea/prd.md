# 空运订单新建与详情页对齐海运

## Goal

用户反馈：空运订单的新建页与详情页应当和海运一样「优秀并且相似」。本期只做
**排版对齐**：让空运（AE/AI）新建与详情页在卡内分组、字段归属、6 列紧凑栅格与
备注呈现上和海运一致，业务人员在海运、空运订单之间切换时看到同一套信息架构，
降低学习成本、提高录入效率。

## 背景（代码调研结论）

入口：`web/src/pages/orders/templates/sea-template.tsx`、
`web/src/pages/orders/templates/air-template.tsx`；新建与详情共用同一构建器，
AE 与 AI 共用空运构建器。两者已共用五卡骨架（业务与客户 / 订舱与运输 /
货物与商业 / 单证 / 人员），差距集中在卡内：

1. **字段归属不一致**：海运把贸易条款、付款方式、合约号放在「货物与商业」首行
   与品类同行，订舱/国外代理放在「订舱与主单」；空运把集运/跨境、贸易条款、
   付款方式、订舱/国外代理、合约号全部放进「业务与客户」
   （`AirCommercialFields.tsx` 的 `AirBusinessFields`）。
2. **备注归属不一致**：海运订舱/配舱/操作备注统一在「订舱与运输 → 备注」小节，
   使用可折叠的 `SeaCollapsibleNotesField`；空运订舱/配舱/普通备注是普通
   TextArea，放在「货物与商业」末尾，操作备注、主单备注分散在运输卡。
   该备注行在 `cols={6}` 中放三个 `span={3}`，第三个换行
   （`AirCommercialFields.tsx:170-206`），属于排版缺陷。
3. **栅格密度不一致**：海运各小节统一 `rowGap: 4` 与 6 列底栅格（长值跨 2 列、
   编号/日期占 1 列）；空运「货物品类」复选框独占整行、「订舱号」独占整行、
   委托件/毛重/体积各占 2 列、航空单证模式以整块单选组呈现而非像海运
   「提单模式」那样嵌入首行字段格、截单/状态与申报件重尺拆成两行各 3 格。
4. 空运单证卡已具备 MAWB/HAWB 页签、运单内容编辑、导入、分单版本历史，
   本期不改。海运拆票/改配、共享箱、船代等属领域差异，不照搬。

## Requirements

- R1 业务与客户卡：与海运同一行序——委托单位（跨 2 列）、委托单位代码、
  订单编号、客户业务号、内部业务号、集运/跨境、订单编号时间（仅新建，行尾）。
  贸易条款、付款方式、订舱/国外代理、合约号移出此卡。
- R2 订舱与运输卡「主单与订舱 / 承运与主单」小节：航空单证模式进入 6 列首行
  （跨 2 列；新建为单选，详情为与输入框等高的只读标签，和海运提单模式同规格），
  其后订舱号、订舱代理、国外代理同行；主单关联方式、共享主单选择、主单身份
  字段（MAWB 号、航空公司、航班号、起运/目的港）与核对提示随后，逻辑不变。
- R3 订舱与运输卡「时刻与申报」小节：截单时间、报关截止、主单单证状态、
  主单申报件数/毛重/体积合并到同一 6 列网格，不再拆两行各留空格。
- R4 订舱与运输卡新增「备注」小节：订舱备注、配舱备注、操作备注、普通备注
  统一使用 `SeaCollapsibleNotesField`，一行四列（窄屏按 FormRow 规则降级）；
  主单备注仍随新建主单的主单字段出现（它写入共享主单，不与本票备注混放）。
- R5 货物与商业卡与海运同序：首行货物品类（跨 2 列）、贸易条款、付款方式、
  合约号（跨 2 列）；危险品联动区；委托品名/货物描述与特殊要求对半；
  委托件数/毛重/体积与接单/货好时间同行；货值、保费、工厂同行；
  详情的航空重量工作区（`airCargoWorkspace`）保持在该卡末尾。
- R6 所有字段的表单 name、校验规则、只读继承、注册次数（付款方式只注册一次）
  与提交载荷保持不变；`airExportFormAdapter` 不改。
- R7 不新增 `maxWidth` 或自定义容器；沿用 `FormRow`/`FormCell`/
  `TemplateFieldGroup` 与 `rowGap: 4`。

## Acceptance Criteria

- [ ] AE、AI 的新建页与详情页四张业务卡的小节标题、字段顺序与上述 R1–R5 一致；
      在 1440px 宽度下无单字段独占整行的空洞（危险品、提示 Alert、整行描述除外）。
- [ ] 订舱/配舱/操作/普通四类备注只出现在「订舱与运输 → 备注」，可折叠，
      一行四列；「货物与商业」不再出现备注。
- [ ] 详情页航空单证模式以只读标签呈现在首行字段格，与同行输入框标签、控件对齐。
- [ ] 新建切换「关联已有主单」时，航线/申报小节与主单备注收起，本票四类备注保留。
- [ ] 表单值与提交载荷不变：`order-kinds/air-export/form-adapter*.test.ts`、
      `air-import/form-adapter.test.ts` 不改动即通过；付款方式仍只注册一次。
- [ ] 受影响的空运模板测试按新布局更新并通过，修改文件 Biome、`pnpm --dir web tsc` 通过。
- [ ] 浏览器实测 AE 新建、AE 详情、AI 新建、AI 详情四个页面，1440px 与 1200px 宽度截图核对。

## Out of Scope

- 单证卡（MAWB/HAWB）交互与能力调整、海运特有业务能力（拆票/改配/共享箱/船代）。
- 后端、Proto、表单适配器与提交载荷的任何变化。
- 海运页面本身的调整。
