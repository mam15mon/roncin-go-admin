# 提成 CNY 前端展示与导出（阶段 3）

## Goal

前端补齐归属月份筛选、CNY 列、详情双口径、预览汇率展示与安全 CSV 下载。
对应计划 §10 阶段 3。

## Requirements

- 契约同步：`pnpm run generate:web-client` 重新生成前端客户端后再实现页面。
- 列表页（`web/src/pages/finance/commissions/index.tsx`）：
  - 新增「归属月份」区间筛选，前端把月份范围转换为含边界日期
    （如 2026-07 至 2026-08 → `2026-07-01` / `2026-08-31`，§4.2.5）；
  - 新增「CNY 提成」列（展示有效 CNY，悬浮或详情区分原始/调整）；
  - 「导出提成」按钮按导出权限显隐（`access` 判断，不硬编码第二套规则），
    导出 CSV 处理 BOM、逗号/双引号/CR/LF 转义与业务文本公式注入，文件名含
    归属月份区间；未选月份时使用导出日期。
- 列表与导出复用同一个规范化筛选对象；前端不重新计算汇率或 CNY 金额。
- 生成弹窗预览区：展示 CNY 折算率、汇率日期与来源；生成成功后以创建响应刷新
  数据，不沿用预览数值。
- 详情（`CommissionDetailDrawer`）：金额区按本位币/CNY 双口径展示原始、调整、
  有效三组金额及汇率信息；已取消提成明确显示「不计入应发」。
- 页面结构遵循 `@/components/ui` 公共模板规范（见 spec/web/frontend）。

## Acceptance Criteria

- [ ] 月份筛选转换正确（含边界、支持单边）；与列表、导出共用同一筛选状态。
- [ ] CNY 列与详情双口径数值与后端一致；预览汇率信息可见。
- [ ] 导出按钮权限显隐正确；导出文件可被电子表格正确打开（BOM/转义）。
- [ ] CSV 公式注入、空结果、文件名和月份边界有测试。
- [ ] `pnpm --dir web lint`、`tsc`、`test` 通过；生成物无手改。

## Out of Scope

- 前端实时折算、明细行 CNY、多币种切换和全站 CSV 框架。
- 后端导出接口、权限清单和业务审计实现。
