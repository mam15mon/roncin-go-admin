# 列设置浮层现代化重构技术设计

## 1. 架构与设计原则

遵循项目全局规范及 Ant Design 6 / ProTable 官方视觉原则：
- **纯白高密度企业级视觉**：主色 `#1677ff`，边框 `#f0f0f0`，背景 `#f5f7fa`，悬浮灰 `#fafafa`；
- **零视觉噪音**：告别密集上下箭头常态陈列，通过微交互（CSS `:hover` 悬停显现）兼顾美观与可用性；
- **拖拽体验强化**：引入 `HolderOutlined` 拖拽把手与 `cursor: grab / grabbing`，清晰传递拖拽心智；
- **严格遵循业务规则约束**：
  1. `lockVisible` 必显列必须始终勾选且禁用；
  2. 无论用户如何反选或全选，必须保证至少保留 1 列可见；
  3. 固定区域隔离（左固定 / 动态 / 右固定）顺序调整不得跨越区域边界；
  4. 搜索过程中禁用拖拽和排序，并展示清晰提示。

## 2. 界面结构与组件布局（Component Blueprint）

浮层外层宽度微调为 `280px ~ 300px`（大厂 ProTable 黄金尺寸），内部纵向三段流式：

```

+--------------------------------------------------+
| 左侧固定列                                        |
| [⋮⋮] [☑] 业务单号 [必显]                 ( ↑ ↓ ) |  <- hover 时才渐显淡灰色箭头
```

## 3. 详细交互与状态机设计

### 3.1 全选 / 半选 / 反选状态
- **全选 Checkbox 状态**：
  - `checked`: 所有可切换可见性的列（排除已隐藏但可切换的列）均已显示；
  - `indeterminate`: 部分显示；
  - `checked === false`: 全部未选（受限于“至少保留1列”，只保留1列或必显列）。
- **点击全选 Checkbox**：
  - 若当前为非全选（含半选），点击后将全部非隐藏列显示（全部勾选）；
  - 若当前已为全选，点击后取消所有非 `lockVisible` 列（若无 `lockVisible` 列，则保留当前列表中排在第 1 位的列可见）。

### 3.2 列表行悬浮态与微操作
- 行容器采用 CSS 类或内联 hover 样式：
  - 正常态：右侧微操作容器 `opacity: 0; transition: opacity 0.15s ease;`；
  - 悬浮态（`onMouseEnter / onMouseLeave` 或 `&:hover`）：`opacity: 1;`；
  - 行背景在悬浮时变为 `#fafafa`，边框圆角 `4px`。
- 保证无障碍支持与测试兼容：
  - 上下移按钮节点在 DOM 中持续存在，`aria-label` 与测试语义不变，单测在模拟交互时完全平滑兼容。

### 3.3 拖拽手柄与视觉反馈
- 左侧增加 `<HolderOutlined style={{ color: '#bfbfbf', cursor: 'grab', marginRight: 6 }} />`；
- 正在拖拽（`isDragging`）时行半透明（`opacity: 0.4`）；
- 拖拽投放时在目标行下方/上方呈现轻量高亮边界。

## 4. 边界处理与容错
- **空状态**：搜索无结果时呈现 Antd 极简 `Empty`；
- **超长字段截断**：字段名过长时使用单行省略（`textOverflow: 'ellipsis'`）结合 `Tooltip`。
