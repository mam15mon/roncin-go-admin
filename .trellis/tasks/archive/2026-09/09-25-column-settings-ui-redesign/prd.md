# 列设置浮层现代化重构（ProTable 标杆级极简纯白交互）

## Goal

重构 `ColumnSettingsPanel` 视觉与交互体验，对齐 Ant Design ProTable 及主流大厂后台标准：
消除满屏上下箭头的视觉噪音、解决顶栏局促折行、引入拖拽手柄与行悬浮高亮微交互、优化全选与重置布局，实现高密度、轻量通透的企业级列设置浮层。

## Background & Problem Statement

在前期 `column-settings-popover` 改造中，列设置已成功实现由居中弹窗向锚定浮层（Popover）的架构收敛。但在视觉与微交互细节上仍存在明显缺陷：
1. **顶栏局促折行**：在 320px 宽度内并排挤入 140px Input 搜索框与 3 个长标签 Radio 按钮，空间拥挤、容易折行断裂；
2. **上下箭头瀑布噪音重**：每一行右侧常态展示 `↑` `↓` 两个按钮，几十列下来视觉被机械重复的箭头严重干扰；
3. **缺少拖拽视觉符号**：虽然支持拖拽，但无 Drag Handle（`HolderOutlined`），用户缺乏“可拖动”的心理认知；
4. **硬线切割感强**：每行使用 `borderBottom: 1px solid #f0f0f0`，列表呈现老旧格子状，缺少现代卡片式悬浮呼吸感；
5. **必显标签刺眼**：实体蓝色 Tag 过度抢夺视线。

## Requirements

### 1. 顶栏重构：全选/重置与全宽搜索两层流式布局
- **第一层（控制栏）**：
  - 左侧：全选/半选 Checkbox（支持一键全选所有非 lockVisible 列、支持反选/清空至保留1列），旁附统计文字（如 `列展示 (12/18)`）；
  - 右侧：轻量文字按钮「恢复默认」，直达目标，消除底部堆叠。
- **第二层（搜索栏）**：
  - 全宽搜索框（`width: 100%`），紧凑尺寸（`size="small"`），支持一键清空（`allowClear`）；
  - 搜索命中即时高亮/过滤，未搜索时平铺展示。

### 2. 列表项重构：拖拽把手、悬浮微操作与纯白通透感
- **行布局与层次**：
  - 左侧常驻低饱和度拖拽把手图标（`HolderOutlined`，灰度 `#bfbfbf`，鼠标悬浮变 `#595959`，`cursor: grab`）；
  - 中间为 Checkbox + 字段标题，支持 Tooltip 完整展示超长标题；
  - 必显列以极简浅灰微标（如灰色 Tag 或轻量文本标记）呈现，不抢视觉主焦点；
  - 右侧操作区：**常态透明/隐藏（`opacity: 0`），仅在鼠标悬停（hover）该行时轻柔淡出**；既保持界面极简，又保留无障碍上下微调能力。
- **视觉风格**：
  - 移除每一行的 `borderBottom` 硬线；
  - 增加行悬浮态：`background: #fafafa`（或 `#f5f7fa`），`borderRadius: 4px`，保持高密度与精致内边距（`padding: 4px 6px`）。

### 3. 分区与底栏收口
- **固定列轻量标示**：保持「左侧固定列 / 动态列 / 右侧固定列」的分区隔离，分区标题字号 12px、色彩 `#8c8c8c`；
- **底栏简化**：
  - 左侧保留状态摘要（如 `已显示 12 / 18`）；
  - 右侧仅在传入 `onOpenAdvanced` 时提供「更多设置」链接；
  - 移除原底部冗余的「恢复默认」按钮（已上提至顶栏）。

## Acceptance Criteria

- [ ] 顶部控制栏布局清爽整洁：左侧 Checkbox 支持全选/半选/统计，右侧快捷「恢复默认」点击生效；
- [ ] 搜索框全宽居中，输入搜索时无水平挤压或断行，支持一键清空；
- [ ] 列表每行左侧具备 `HolderOutlined` 拖拽把手，支持平滑上下拖拽调整顺序；
- [ ] 列表每行去除了常态下密集的上下箭头，操作仅在鼠标 hover 时淡出，消除视觉噪音；
- [ ] 列表项去除硬边框底线，悬浮具有统一浅灰圆角背景；
- [ ] 必显列（`lockVisible`）逻辑严格保持不变（不可取消勾选、不随全选/清空而隐藏）；
- [ ] 至少保留一列可见的底线逻辑保持不变；
- [ ] 原有单测及新增视觉/交互单测全部绿灯通过，`pnpm run check:fast` 顺利通过。

## Out of Scope

- 不变更服务端契约或数据持久化逻辑（保持已有的即时回调与本地存储机制）；
- 不调整其他业务页面业务逻辑，仅升级公共组件内部渲染表现。
