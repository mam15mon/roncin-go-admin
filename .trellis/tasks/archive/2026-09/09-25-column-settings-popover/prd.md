# 列设置浮层化改造：向业界标准交互收敛

## Goal

将全站统一列设置（`web/src/components/ui/column-settings/`）从「居中弹窗 + 草稿 + 保存确认」
改为「齿轮锚定浮层 + 即时生效 + 自动持久化」，向业界通行形态（ProTable 内置列设置、
AG Grid / Notion / Airtable 等）收敛，消除「调整时看不到表格效果」的盲调体验与
「隐藏一列要四步」的操作摩擦。

## 背景与问题

现形态为 640px 居中 Modal，存在四类摩擦：

1. 弹窗遮挡表格，显隐/排序调整无法所见即所得，需保存关闭后验证，不对再重开；
2. 偏好已本地化（localStorage 同步写入），保存本为瞬时，「弹窗 + 保存按钮」仪式无必要；
3. 原生拖拽无落点指示、边缘不自动滚动、搜索时禁用排序，长距离移动仅能逐格点上下移；
4. 单列操作（隐藏、固定）无表头就近入口（本期不做表头菜单，列为后续可选增强）。

## Requirements

- **R1 非阻塞浮层**：点击「列设置」齿轮按钮弹出锚定 Popover，表格全程可见可操作；
  取消居中 Modal 形态。
- **R2 即时生效**：显隐勾选、拖拽排序、上下移、恢复默认均立即作用于表格，无保存按钮、
  无草稿确认步骤；浮层外点击关闭。
- **R3 自动持久化**：每次变更即时写入浏览器本地偏好（沿用现有
  「表格标识 + 用户 + 组织」隔离口径）；写入失败时明确提示且不声称已保存，
  页面内效果保留。
- **R4 既有能力平移不缩水**：搜索列名、全部/已显示/已隐藏筛选、左固定/动态列/右固定
  分区、必显列锁定（不可隐藏）、至少保留一列、结构列排除、搜索中禁用排序并提示、
  恢复默认、禁用入口与原因提示——全部保留。
- **R5 费用台账收敛**：费用台账（`finance/fees`）列显隐/排序改走统一浮层；
  行配色（原「高级设置」页签）收敛为浮层底部「更多设置」打开的二级弹窗，
  仅含 RowColorSettings，配色调整同样即时生效并独立持久化。
- **R6 调用方契约一次性同步**：hook 返回契约调整为 `{ columns, entry }`，
  仓库内全部调用点同步更新，不保留 `modal` 死接口、不留兼容分支。
- **R7 死代码清理**：`ColumnSettingsModal`、`persist` 关闭项、旧测试等
  随本次改造一次性移除，无残留引用。
- **R8 交互质量底线**：浮层内列表滚动区域高度合理（长列表可滚动）；
  浮层关闭再打开，状态与表格一致；拖拽/键盘操作不误关浮层。

### 明确不做（本期范围外）

- 表头 hover 就近菜单（隐藏/固定单列）——列为后续可选增强；
- 拖拽落点指示线、边缘自动滚动、虚拟滚动等拖拽体验深度优化；
- 列宽、固定区调整（把普通列设为固定列）进入设置浮层；
- 旧 localStorage 视图数据迁移（正式上线前无生产契约，开发期偏好按默认重建）。

## Acceptance Criteria

- [ ] 点击齿轮出现锚定浮层，表格不被遮挡；勾选某列复选框，表格列即时增减；
      拖拽或上下移后表格列序即时变化。
- [ ] 任一变更后刷新页面，偏好保留；换用户/组织登录后隔离不串用（沿用现有口径）。
- [ ] localStorage 不可写时（mock 失败）出现明确报错提示，浮层保持打开，页面内仍生效。
- [ ] 必显列不可取消勾选；仅剩一列可见时最后一列不可取消；结构列不出现在列表中。
- [ ] 搜索时排序（拖拽/上下移）禁用并出现既有提示；清空搜索后恢复。
- [ ] 「恢复默认」即时生效并持久化。
- [ ] 费用台账：浮层可完成列显隐与排序；「更多设置」打开行配色弹窗，改色即时生效、
      刷新保留；原「列配置/高级设置」双页签弹窗与 `onOpenColumnConfig` 绕行链路移除。
- [ ] `grep` 确认 `ColumnSettingsModal`、`persist: false`、`settings.modal` 等无残留引用；
      `pnpm --dir web tsc`、改动文件 biome、相关定向测试全部通过；收尾 `pnpm run check:fast`。
