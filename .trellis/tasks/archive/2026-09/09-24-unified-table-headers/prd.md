# 全站表头设置界面统一

## 目标与用户价值

统一项目所有表格的「表头设置／列设置」界面，消除不同页面在配置入口、字段选择、排序与保存操作上的割裂感。用户已明确本次对象是设置界面，不是表格列标题行的视觉样式；并明确要求目前没有设置入口的表格也必须补齐。

本次交付为 Trellis 规划文档；任务保持 planning，以下设计方案待评审，尚未批准产品代码实施。

## 已确认现状

- 主数据模板启用 ProTable 内置列设置：`web/src/components/ui/master-data-template/MasterDataTemplate.tsx:734`；订单列表直接使用 ProTable，未显式统一其设置界面：`web/src/components/ui/order-list-template/OrderListTemplate.tsx:595`。
- 订单费用独立小弹窗支持搜索、显隐、上下移动、必显列、恢复默认、确定与取消：`web/src/pages/orders/components/fees/FeeColumnSettingsModal.tsx:61`。偏好按用户和组织隔离于浏览器，应收／应付共享：`web/src/pages/orders/components/fees/feeColumnPreference.ts:2`。编辑期间禁用设置入口：`web/src/pages/orders/components/fees/OrderFeeTableTabs.tsx:230`。
- 财务费用台账独立大弹窗包含字段卡片、拖拽、显隐、分页、默认排序、行配色与服务端保存／重置：`web/src/components/ui/finance-ledger-template/TableColumnConfigModal.tsx:41`。由 `web/src/pages/finance/fees/index.tsx:517` 使用，台账模板关闭内置设置：`web/src/components/ui/finance-ledger-template/FinanceLedgerTemplate.tsx:580`。
- 有些表格显式关闭 options，另有普通 Table 与编辑表格。不能仅替换两处弹窗就宣称全站完成；实现前需形成逐入口清单，区分已有设置、默认内置设置及无设置入口。

## 建议需求

- R1 统一命名与入口：统一为齿轮图标「列设置」，图标入口有同名提示；同一表格只出现一个入口。覆盖所有已有、隐式内置及当前无设置入口的表格，包括普通列表、详情、弹窗、抽屉、嵌套明细、导入预览和可编辑表格。
- R2 一套交互、两种容量：标准版用于普通列表、主数据及订单费用；增强版用于财务费用宽表。共用字段配置区，增强版增加高级设置，不再另用一套卡片交互。具体结构见 design.md。
- R3 公共字段操作：搜索列名、显示数量、勾选显隐、排序、恢复默认；必显／固定／无权限列遵守所属表格约束。不得给无权限字段提供可用选项或在保存后重新显示。
- R4 草稿与提交：设置打开后编辑草稿，统一「恢复默认／取消／保存」；取消与关闭丢弃草稿；恢复默认先修改草稿，保存后生效。保存失败保留草稿并反馈错误，成功后表格与再次打开的设置一致。不得谎报持久化成功。
- R5 搜索与排序：搜索只筛选设置列表，不修改表格；搜索期间禁用顺序调整并提示清空搜索后排序，避免以筛选后序号操作完整顺序。无搜索时拖拽与上下移使用同一完整字段顺序。
- R6 保留业务能力：财务分页、默认排序和行配色进入增强版高级区域；订单费用必显规则、编辑中禁用、应收应付共享及用户／组织隔离维持正确；已有固定列配置能力在统一界面中保留。
- R7 全站覆盖可追溯：逐表记录入口、组件来源、配置能力、保存范围及迁移结果。无设置入口的表格全部新增标准版，不能以 options=false、toolBarRender=false、普通 Table 或字段少为由跳过；无工具栏时在表格上方右侧提供紧凑入口。相同结构的重复嵌套表可共享偏好，但每个可操作表格须能找到入口。

- R8 新增入口的默认行为：以当前业务列显隐和顺序作为默认值；选择、展开、操作等结构列不作为普通可隐藏字段。录入必填且隐藏会阻断操作的列必显；普通数据列至少保留一列。分组表头在组内调整叶子列，不破坏分组结构或跨固定区域排序；有合并单元格／汇总行的表格同步保持列对齐。全部数据列必显的表仍提供设置入口并说明限制。
- R9 新增及原本未持久化的普通表设置建议按用户 ID、组织 ID、稳定表格标识保存到浏览器；表格标识按业务视图定义，不使用实体 ID，避免不同表串用、逐订单产生配置。财务已有服务端偏好和订单费用已有本地隔离继续使用。新存储写入失败时保留设置草稿并明确报错，不静默降级或声称保存成功。

## 不在本次范围

- 表格表头底色、字号、密度、表体、搜索区与业务工具栏整体改版。
- 新增通用服务端偏好平台、共享视图、多套方案命名、跨设备同步、权限体系或后端业务契约变更。
- 借机改写表格请求、分页数据流或统一各业务默认列集合。

## 验收标准

- AC1（R1/R2/R7）：盘点清单内每张表格均有可达的列设置入口并归入标准版或增强版，无遗留第三种设置交互；入口命名、标题、底部按钮一致。
- AC2（R3/R5）：搜索、显隐、恢复默认、顺序调整在两版语义一致；空搜索结果、首尾移动边界、隐藏列重新显示均正确；搜索中不发生错位排序。
- AC3（R4）：取消／关闭不修改当前表格或已存偏好；保存成功后重新打开结果一致；保存失败不丢草稿；恢复默认后取消可完整撤销。
- AC4（R6）：财务分页、排序、配色保存后生效；订单费用必显与权限限制不可绕过，编辑中不可打开，应收应付同步且用户／组织间不串用。
- AC5（R2）：1366×768、1920×1080 下配置主体可滚动、底部操作可见，字段长名称可完整查看；两版提供可对照截图。拖拽提供按钮替代操作，图标按钮有可访问名称。
- AC6：定向交互测试与前端门禁通过；全站入口清单和代表页面的浏览器验收记录完整。未运行检查必须注明原因，不以组件 mock 测试替代实际布局验收。

- AC7（R7/R8）：原无入口的普通 Table、禁用内置工具栏的 ProTable、编辑表格及嵌套表均可打开设置；当前列定义成为恢复默认基准，结构列不丢失，必填录入、分组表头、合并单元格与汇总行无错位。
- AC8（R9）：新增普通表偏好刷新后恢复，同一业务视图不同实体可复用；不同用户、组织及表格互不串用。存储失败可见且草稿保留。
