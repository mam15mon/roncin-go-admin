# 美化页头面包屑为现代紧凑微交互流

## Goal

将 `PageHeaderShell` 页头与面包屑重构为现代高密度单行流：精简冗余的“返回列表”纯文字按钮为轻量返回图标与 Tooltip 提示，为面包屑增加 Hover 变蓝与微浅底微交互，升级生硬手写斜杠为精致分隔符，保持 48~52px 纯白吸顶高密度。

## Requirements

1. **返回操作精致轻量化**：
   - 将带文字的返回按钮优化为 28px × 28px 的轻量图标按钮，搭配 Tooltip 提示（显示 `backText`）。
   - 保留 `aria-label={backText}`，确保单测与无障碍可访问性。
   - 移除生硬突兀的垂直分割线 `Divider`，以轻微间距自然过渡。
2. **面包屑样式与微交互升级**：
   - 面包屑链接支持平滑 Hover 动效（悬停时文字变蓝 `#1677ff`，轻微胶囊浅底背景 `#e6f4ff`）。
   - 分隔符样式优化为精致柔和的斜杠（色值 `rgba(0, 0, 0, 0.25)`，微调字号与边距）。
3. **视觉层次与纯白高密度规范**：
   - 主标题、副标题与 Tag 保持清晰层级，吸顶栏高度维持在紧凑舒适的 48~52px。
   - 样式通过 `global.less` 中的 `.roncin-page-header-shell` 规范类组织，避免散乱内联样式。

## Acceptance Criteria

- [x] 返回按钮精简为图标形态，悬停提示返回目标，无障碍与单元测试通过。
- [x] 面包屑链接具备 Hover 变蓝高亮与微浅底动效。
- [x] 分隔符斜杠视觉柔和，不再生硬单薄。
- [x] 现有测试套件（`PageHeaderShell.test.tsx`、`OrderPageHeader.test.tsx`）全部通过。
