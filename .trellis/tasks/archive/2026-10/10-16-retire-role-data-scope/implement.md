# 实施与验收计划

1. 核对研究与规范，分后端和前端两个互不覆盖写入范围的实现代理。
2. 后端先改 Proto、Ent Schema，运行生成器；同步角色写入/读取、认证与授权画像、初始化、审计和候选判定，移除所有活动存储字段读取/写入；正式迁移先禁用 self 再删列。
3. 前端删除角色范围表单、列表与筛选、提交默认值和角色摘要范围展示；保留功能权限配置及搜索回归。
4. 实现后按风险补充定向测试：公司隔离、系统治理、创建编辑无范围、防提权、旧 self 停用、迁移升级及冷启动。
5. 独立 check 代理全范围审查，自修局部缺陷；主代理检查生成差异、迁移与边界，运行 pnpm run check:fast 和必要真实 PostgreSQL 集成，确认无假绿。
6. 同步规格，git diff --check，按 Conventional Commits 中文提交本组变更。归档本任务，记录日志。
7. 工作区干净且未有并发 main 修改时切 main 合并（优先 ff，必要时正常 merge）；检查 ancestor 及工作区，git branch -d 删除已合入的本任务和前一权限查找分支。
8. 逐条核验 PRD AC1-AC6 后完成 goal，报告提交/检查/合并清理事实。
