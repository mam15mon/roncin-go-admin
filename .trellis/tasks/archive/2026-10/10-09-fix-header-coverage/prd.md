# 修复固定顶部栏覆盖缺口

## 目标
修复全局固定顶部栏在侧栏展开、折叠及正文滚动时的覆盖缺口，让标题与操作区正常铺满顶部栏。

## 当前问题
全局样式同时给 header 外层和内部混合布局容器设置侧栏偏移与扣减宽度，折叠时内外宽度不一致，正文可能从顶部空缺露出。浏览器进一步确认折叠规则未匹配实际根结构，外层仍从 208px 开始；组件默认折叠占位 64px 与 CSS 的 48px 不一致。

## 范围与约束
- 仅修复全局顶部栏布局、必要的响应式关联样式，以及 AppLayout 折叠菜单的 48px 宽度配置。
- 沿用侧栏展开 208px、折叠 48px、顶部栏高度 48px 的现有约定。
- 固定外层提供不透明背景；内部容器铺满外层。
- 不通过工作台间距或增大 z-index 掩盖问题；不更改业务逻辑和接口。
- 按实现后验证原则，在真实浏览器检查尺寸与滚动覆盖，避免依赖 jsdom 的无布局断言。

## 验收标准
- 桌面侧栏展开时，固定 header 从侧栏右边界延伸至视口右边界。
- 桌面侧栏折叠时，固定 header 左边界为 48px；内部不再重复扣除 208px。
- 两种侧栏状态下，滚动正文后 header 仍完整覆盖正文，页签栏紧接顶部栏，无漏出空隙。
- 移动端 header 覆盖视口宽度，标题和操作按钮不因重复扣宽而偏移。
- 使用真实 ProLayout 和仓库全局样式验证关键边界，完成风险匹配的前端门禁与 git diff --check。
