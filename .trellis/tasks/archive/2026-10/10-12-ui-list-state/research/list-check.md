## 实现期间发现并交接

1. 订单 RemoteSelect 恢复名称仅携带 initial label，用户改选 ID 后可能把旧名称绑定到新 ID。实现者已修复为完整 value/label 配对保活，改选同步更换配对、仅 value 匹配时加入候选；最终源码及“甲改乙后候选缺失仍保持乙名”的回归已核对。
2. 订单标签候选为 pageSize=200 的首批数据；仅恢复 tagIds、未保留选择名称可能显示裸 ID。现以 `tagIds:<ID>` 保存所选名称并与首批候选合并，原始 ID 查询契约不变。更多筛选使用 hidden 保留五类日期和其它字段注册，已验证收展及重置。
3. 实现者回归发现 RemoteSelect 缺省空 options 每渲染变化引发 effect 重复设置。现固定 `EMPTY_SELECT_OPTIONS` 引用；仅局部稳定默认值，没有引入新架构。
4. 审查者补测时部分 ActionType mock 结构转换被类型检查拦截，已修为显式 unknown 中转，未关闭规则或扩展产品类型。
