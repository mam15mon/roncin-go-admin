# 修复整票费用审核审查问题

## 目标与授权
用户已要求修复审查问题，并同意建立任务。保持一个订单一包费用审批、自审按权限允许、亏损原因必填及钉钉仅提醒的既定流程。

## 验收标准
- [x] 审核及提成发放请求失败或返回空响应时，不显示成功、不关闭弹窗、不触发成功回调，保留输入以便重试。
- [x] 跨订单应收应付对冲，预览、创建、确认及月度申请采用一致的计提订单集合。
- [x] 费用录入和审核均使用八位银行家舍入，合法费用可审核，错误金额仍拒绝。
- [x] 审核/补录与月度申请遵守一致授权父实体及订单锁序，并发无锁序死锁，实时权限校验仍有效。
- [x] 补录创建、驳回、撤回、批准后刷新审批与建账能力，失败不误刷成功。
- [x] 审批意见统一最多 1000 个 Unicode 字符，中文不因字节数触发服务端错误。
- [x] 待审补录能够撤回并预填重提，同时不能重复另建待审申请。

## 边界
仅修复七项已复现问题，不更改全局请求客户端错误契约、不增加权限或审批模式、不重置开发库、不自动处置既有待审申请。实现后补充触发场景及相邻路径回归，使用独立测试库。
