## 6. 生成与质量门禁

先运行变更所需生成命令，再最小检查，最后全栈门禁：

```bash
go -C server generate ./...
make -C server api
pnpm run generate:web-client
pnpm run generate:permission-keys
git diff --check
```

- 开发中运行受影响 Go 包与具体测试、`pnpm --dir web exec vitest run <实际测试文件>`、修改文件 Biome 和 `pnpm --dir web tsc`。

- 如修改回调生产入口、构建配置或静态路由，额外执行对应生产构建；普通表格样式变更不单独增加构建。
