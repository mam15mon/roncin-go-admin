## 独立审阅发现与处理

1. 仓储使用锁等待前的 now 判断冷却/过期，可能让等待期间已过期的验证码消费或激活。改为取得挑战锁后用当前 UTC 判断，并由仓储建立新代 60 秒/5 分钟时限；删除三个内部方法无效的 now 参数，一次同步调用方与 mock。新增真实 pg_locks 观察的持锁边界回归。
2. 两项历史迁移测试把后续完整迁移链混入原快照，新增合法用户字段导致 JSON 差异。将它们限定至各自目标迁移，继续验证原有身份/成员/角色绑定不变；本次新增投影由专属迁移测试验证。
3. 新增迁移表名未按仓库双引号风格声明，迁移清单校验未识别该表。统一 SQL 引用并定向复验清单及正式回填迁移，保持原约束与 Schema 不变。
4. 发送成功中文提示在统一 ok(ctx, ...) 中被覆盖成 OK。仅调整此 handler 设置提示的顺序，并以 HTTP 响应断言中文，不改全局成功信封。
5. 前端规范首条旧入口仍为“管理员账号”，已同步“账号登录”；失败审计与等价格式限流、变号再改回废弃挑战规则同步规范。
