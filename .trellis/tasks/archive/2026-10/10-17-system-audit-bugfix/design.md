# 技术设计

## 行为差距与边界

失败识别位于写调用后的成功分支；身份隔离位于业务工作区查询客户端生命周期；导出语义位于财务字段映射与 CSV 序列化；数据库覆盖位于 CI 与专用验收。各自修根因，不借权限改动或请求层契约替换绕开问题。

## R1：写入结果

保留 request 全局处理错误后返回 undefined 的契约。盘点全部生成客户端写调用、onFinish/onOk/useMutation 成功分支：消费失败先返回，实体报文核对必要 ID，success:false 不成功，空响应接口按实际契约判定。大量同类判断确有共用时允许在 utils/api.ts 提供最小类型守卫，不引入命令框架。确认弹窗失败必须保留 Promise 拒绝/false 语义。覆盖后台、客商、订单、财务、公用 CRUD；读取仅处理受影响相邻路径。

## R2：工作区缓存边界

OrganizationWorkspace 已按 userId:organizationId keyed 重建，在此业务树设独立 QueryClientProvider，工厂复用统一默认策略；公开登录预热保留入口客户端。客户端归工作区，卸载取消并清旧业务缓存，旧响应不得注入新实例；无需依赖所有页面 queryKey 人工携带身份。检查直接导入全局客户端的生产代码（体检仅 main 引用）。真实生命周期回归覆盖同公司换用户、公司往返、旧响应迟到、匿名状态，不能打断公开钉钉配置及 Cookie 串行。

## R3：财务导出

显式类型化导出列，禁止从 React render/原始 dataIndex 猜 CSV。六类领域页面声明真实字段，公共模板只消费声明和下载。金额/币种独立列，汇率比例数量保精度，enum 复用显示映射，datetime 复用格式函数。公共 CSV 可复用提成转义思想但不跨页面深引。UTF-8 BOM、CRLF、双引号转义、文本公式保护且保留受控负数，空结果不下载，成功清理链接和 URL。保持选中行/当前页范围并明确提示，不新增全量接口或循环翻页。

## R4：数据库验证

CI 给完整 data/migration 包专用连接及迁移开关；DATABASE_SOURCE 同步绑定隔离库，避免子进程继承开发配置。包间使用独立库或分步执行，防止前态争用。本地用一次性任务前缀库执行同等验证，只清理本次记录创建的资源。修复真实执行暴露的过期夹具、迁移冲突和产品缺陷，不减少断言或加 SKIP。

## 协作与回滚

三个实现边界：写入反馈；缓存隔离（main/QueryClient/工作区及测试）；财务导出（CSV/台账模板/显式映射）。主会话处理 CI、集成、spec 和 Git。财务 index.tsx 同时编辑时，仅各自负责写操作分支或导出 imports/props，禁止回退他人编辑或全文件格式化。

按验证批次提交，回滚用精确 revert，不改用户数据。最终干净工作树切 main 快进合并，核对祖先关系后 git branch -d，仅清理本次分支，不推送或删其他远端分支。
