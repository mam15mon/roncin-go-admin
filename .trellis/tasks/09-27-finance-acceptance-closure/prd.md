## 验收标准

- [ ] A1（R1）：四项原用例真实执行到目标断言且 PASS，无跳过、删除测试或放宽业务约束；data / migration 两包真实库全量完成，失败与跳过逐项说明。
- [ ] A2（R2）：三类财务 HTTP 场景对运行中的服务完成真实写入与重读，应收/外币追溯至提成，应付追溯至付款核销；只做语法或前置条件检查不算通过。
- [ ] A3（R2）：浏览器在真实服务上完成同一订单的“录费用→建账单→登记收款并核销→查看对应提成”，必要的计提操作遵循当前产品流程；刷新后仍能核对金额、关联与状态。
- [ ] A4（R3）：报告包含提交 SHA、运行时间、命令、环境标识、PASS/FAIL/SKIP/未执行、关键业务编号和证据路径；自动化浏览器与人工走查明确区分，不声称用户已人工验收。
- [ ] A5（R3）：风险匹配门禁通过，无本任务回归；未完成项不得因“存量同因”或“组件已通过”而勾选完成。
