## D. 风险对应验证

实现后补：

- 利润：应收 10,600/未税 10,000，应付 6,360/未税 6,000，利润 4,240/4,000；不同税率、手工/系统汇率、半偶舍入、未建账也计；批准替换旧叶子不重计，待审输入不计。
- 业务日期：出口 ETD/进口 ETA、AE 主单权威、UTC 跨本地日、月底跨月、缺日期辅助桶及日期筛选后的数量提示；禁止回退创建时间。
- 人员与关联：多岗位/同一人员多岗不能倍增费用；客户按订单客户，结算单位按实体事实，不跨公司候选/查询/导出。
- 流水：DRAFT/CONFIRMED/CANCELLED、未核销预收付、部分/反核销、多次核销均不重复实际金额；对冲不计现金。
- 账龄：due 当天、差 1/30/31/60/61/90/91 天、未设 due；部分核销/对冲、草稿对冲、撤销后恢复、账单取消；多个明细 join 不乘金额；五段＋未设日期等于合计。
- 分页/完整性：1、200、201 边界；多页数据翻页不改合计/图；导出 10,000 恰好可导、超限显式失败；金额桶不跨币相加。
- 一致性：真实并发控制查询首条读取后发生财务动作，当前响应同一快照、下一次更新；不依赖固定 sleep。
- 前端 wire：默认 false/0 省略、显式零、非零、optional 未设、真实必需字段缺失；迟到请求不更新指标/图；取消/失败不下载；新权限正反例。

定向 Go biz/service/data PostgreSQL；前端分文件 Vitest 和改动文件 Biome/tsc；schema 如变更验证正式迁移；生成重跑幂等。提交前 `git diff --check`；阶段最终验收 `pnpm run check:fast`，构建仅本次实际改生产入口/依赖或发布要求时运行。
