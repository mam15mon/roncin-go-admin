# 技术设计

## 边界与数据流
复用现有认证 service 的公开配置和 Cookie。Go webassets 与 Vite HTML 中间件从本次合法启用配置输出 iframe，URL 使用标准 URL 工具追加 iframe=true，属性做 HTML 转义，仍保留一次性 JSON 配置。

iframe 置于 #root 之外，避免 createRoot 清除。前端从专属接管模块认领与当前配置完整匹配的实例；不改其 src、不移动节点。用扫码占位区域的几何位置对齐该外部 iframe，监听窗口/布局变化并清理。普通 SPA 返回及刷新由现有 React 路径创建新 iframe，不预建通用框架。

加载到接管之间的事件与状态按最薄必要机制处理：提前 iframe 若隐藏至前端接管则不允许用户在未安装认证监听时扫码；已完成的 load 不可依赖 React onLoad 再次触发。不得丢失可操作阶段的认证消息。实现时验证浏览器加载行为，不用跨浏览器缺失的 DOM 原子移动 API。

## 生命周期
首次配置消费并验证后只认领同次响应的 iframe；失败/禁用/过期/不匹配时销毁预载实例。刷新、管理员模式、认证开始及路由退出先停用并清理旧实例，保持配置查询串行与状态校验。

## 契约与兼容
不修改公开 API，不需生成物或迁移。仅精确登录 HTML GET 动态注入，保持 no-store 和 Cookie 属性；静态产物不含授权 URL。Go 与 Vite 的输出约定用测试对齐。

## 回滚
整体回退本组提交恢复仅内嵌配置的加载方式；数据库无变化。
