# 海运进口及固定服务进度闭环

## 目标与范围

父任务：`.trellis/tasks/11-15-hgj-business-alignment`。本子任务只承担以下可独立验收的交付，完整目标由父任务统合。

- 实现SI合法IMPORT建票/详情/修改、真实MBL/航程/HBL/箱货/费用及同方向共享。
- 新增固定每票进口承接五环节、换单代理、实际时间、派生进度与不可变服务事件；无服务与未完成分别表达。
- SI审核快照修订CHECK、恢复/放货引用真实单证；按票适用性参与完结；已结案变更先重开。
- 接通SI适用的海运内容维护/版本/制作归档与HBL输出；不复制海运出口页面或通用历史单证。

## 验收标准

- [ ] SI直单/主分单（沿用海运现有合同）、箱货、费用、锁、终止恢复及完结真实闭环。
- [ ] 五环节任意承接子集、并行完成/撤回、范围变化原因和历史；不适用不阻断，不自动推进其他票。
- [ ] SI相关主单/快照/权限/版本/范围拒绝场景和正式迁移均通过，SE保持回归。
