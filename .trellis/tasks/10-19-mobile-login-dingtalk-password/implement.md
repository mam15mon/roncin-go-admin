## 分工和依赖

本功能是单个联合验收闭环，保留一个任务。实现代理负责下述产品代码及针对性测试，检查代理在实现完成后核查并修正范围内问题；主会话维护任务产物、协调冲突、审阅和提交。实现、检查有先后关系，不让两个代理同时修改 auth 等共享文件。每次代理派发以 `Active task: .trellis/tasks/10-19-mobile-login-dingtalk-password` 开头，明确文件所有权、共享工作区及不得覆盖其他人改动。

## 阶段二：后端认证闭环

- [ ] 联合解析手机号/用户名候选并去重，重复或不同用户重名明确拒绝；保留本地管理员和同用户双命中，复用工作台选择规则。
- [ ] 扩展凭据快照与最终会话建立复核，阻止旧密码先验证、重置后仍建会话；手机号审计统一脱敏。
- [ ] 实现每手机号 60 秒冷却、IP 20 次/10 分钟有界限制和不可使用挑战；未知目标同响应形状、同冷却。
- [ ] 实现随机验证码/令牌、仅摘要持久化、PENDING→READY/FAILED、外部发送在事务外、结果未知不激活和当前代条件更新。
- [ ] 实现 5 分钟有效、错误计数提交、第 5 次作废、重发失效、一次消费；用户→组织/成员→挑战→会话固定锁序，处理首次创建竞争。
- [ ] 同事务密码写入、消费、全会话撤销和审计；校验当前绑定、重复号码及账号状态；管理员重置废弃本用户挑战。
- [ ] service 处理请求/响应、no-store 与成功后 Cookie 清除；不在传输层写业务规则，不新增独立请求主机或秘密配置。
- [ ] 功能实现后补针对性测试（禁止 TDD），覆盖请求边界及相邻路径。

## 针对性验证矩阵

| 层面 | 必测行为 |
| --- | --- |
| biz | 账号解析、同用户双命中/跨用户冲突、归一化、未知/待分配/停用、验证码时限与次数、无有效工作台、消息失败与结果未知 |
| data/PostgreSQL | 并发首次创建/发送只一次、重启冷却、错误计数不回滚、并发消费只一人成功、验证码与密码原子回滚、全部旧会话失效、旧凭据建新会话竞争、号码变更/重复/管理员重置后挑战失效 |
| migration/PostgreSQL | 冷启动、已有手机号正式回填与 Go 归一化等价、缺失与重复数据保留、CHECK/索引与 Ent 元数据一致、身份/授权/密码不变 |
| service/server | 公共接口 access 注解、字段/错误信封、Cookie 清理、缓存头、统一元数据 IP、日志不含敏感值 |
| web | 正确客户端载荷、手机号/本地账号、倒计时及 429、请求防重和迟到响应、首次/找回与重置成功、单/多组织及扫码相邻行为 |

开发过程中只运行实际改动相关用例和文件检查：

```bash
go -C server test -p 32 ./internal/biz ./internal/service ./internal/data ./internal/server -run '<本次实际新增与受影响的测试名>'
pnpm --dir web exec vitest run src/pages/user/login/index.test.tsx <实际新增的密码找回测试文件>
pnpm --dir web exec biome check <相对web的实际修改文件>
pnpm --dir web tsc
git diff --check
```

以上尖括号为实施后替换的测试选择条件，不作为可原样运行的命令。重型组件单测试文件不超过 10 个用例，超过 20 秒按功能拆分。

真实 PostgreSQL 使用现有 `integration_test_helper_test.go` 创建随机 Schema、执行有序正式 SQL；显式提供专用 `RONCIN_INTEGRATION_DATABASE_SOURCE`，不读取/打印连接串，不指向日常开发库。涉及 Schema 初始化用例禁止 t.Parallel，不使用 Ent Schema.Create。记录实际 PASS/FAIL/SKIP，Skip 不得算验证通过；具体锁/并发测试要实际进入断言。
