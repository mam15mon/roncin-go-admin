## 验证命令及执行时机

以下是后续实施时的命令；本轮文档编写不运行迁移、种子或产品门禁。

- 生成：go -C server generate；make -C server api；pnpm run generate:web-client。
- 权限 Manifest 变更时：pnpm run generate:permission-keys。
- 后端定向：go -C server test -p 32 ./internal/biz ./internal/data ./internal/service -run 'AirExport|OrderTransition|FeeQuantity' -count=1。按最终测试名称调整，确认实际命中且集成测试不跳过。
- 前端定向：pnpm --dir web exec vitest run <实际测试文件>。实施后替换占位，路径相对 web/，不可原样执行。
- 类型与架构：pnpm --dir web tsc；pnpm run check:architecture。
- 计划结构：python3 .trellis/scripts/task.py validate .trellis/tasks/10-20-air-export-business-loop。
- 提交前：git diff --check；最终全栈验收：pnpm run check:fast。

不以静态检查代替真实数据库与浏览器证据；未执行项必须明示。构建仅在涉及构建/依赖/发布验收时运行。

## 风险与回退检查点

1. 订单准入和状态机：SE/AE 分开验证，不能为 AE 放松所有业务类型。
2. 费用预览：来源显式、缺数据不回退、已有费用不自动重算。
3. 公共页面/人员 hooks：覆盖组织切换、返回路径和 SE 原表单。
4. 共享主单为必需范围：模型冻结前审查多票权限、固定锁序、解除关联、空运快照及运输信息归属；费用不自动分摊。
5. AE 数据存在后：回退保留当前数据契约，不删表或重置业务库。
