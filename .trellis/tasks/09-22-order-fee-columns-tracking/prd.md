# 订单费用录入与财务追踪增强

## 目标与状态

让操作人员在订单费用页高效录入、按需查看税额与折本币金额，并在具备财务权限时追踪关联账单。借鉴竞品可配置表头，不以达到 37 列为验收目标。

用户已同意创建 Trellis 规划任务。本轮交付计划；以下为待最终审阅的推荐方案，不代表已批准实施。任务保持 planning。

## 背景与已确认事实

完整证据和 37 项对照以 `research/field-matrix.md` 为唯一研究记录。

- 费用已有税率、含税标志、税金、不含税总额、本币金额与标签（E1/E3），主要缺口在订单主费用表的展示与配置。
- 主费用页已经采用纵向应收／应付双表和行内编辑（E2）；本任务保留该交互。
- 财务接口已有活动账单号与关联账单整体进度（E4/E5/E6），其权限与订单费用读取不同（E10）。
- 台账发票列和核销金额列不能算作已完成数据能力（E7）。本期不展示未接通的占位功能。
- 现有财务台账偏好与订单费用不是同一场景（E8）。

## 本期需求

### R1 列设置与个人偏好

- 在订单主费用页提供「列设置」，可搜索列名、显示／隐藏可选列、调整顺序、恢复默认。
- 设置在确定后生效；取消不改变表格。恢复默认同时恢复顺序与显隐。
- 推荐同一用户、同一公司、同一浏览器内持久保存；应收／应付使用同一列配置，切换订单继续生效。跨设备同步留待真实需求。
- 默认展示：状态、费用名称、结算单位、计费单位、数量、币种、单价、总金额、汇率、发生日期、备注及操作。
- 费用名称、结算单位、计费单位、数量、币种、单价、发生日期及操作在本期保持可见，避免必填编辑项被隐藏；操作列固定右侧。
- 调整配置期间不能丢失未保存费用；推荐正在编辑时禁用列设置，并明确提示先保存或取消编辑。

### R2 只展示有真实来源的附加列

- 可选列：费用代码、税率、税金、不含税总额、折本币金额、费用标签。
- 税率与计算结果只读；最终金额以保存后服务端返回为准，本期不扩大税率编辑范围。
- 区分输入单价的含税标志与含税总金额；不得因旧行 taxInclusive=false 而展示错误的单价口径。
- 折本币金额同时标示本位币，不把不同币种原币相加，也不拿最新汇率重算已保存快照。

### R3 关联账单追踪与权限

- 有财务费用读取权限时提供可选「账单号」「关联账单财务进度」，并提供已有订单财务详情入口。
- 财务进度明确表示关联账单整体状态，不称为单条费用核销金额、对账确认或单条费用开票完成率。
- 无财务读取权限时不请求或展示这些关联信息，仍可按原权限使用订单费用功能；不得为列设置要求额外财务权限。
- 未建账、已作废、加载中、加载失败分别表达，不能把请求失败显示成未建账。
- 新增、修改、确认、撤回、作废及建账完成后，相关费用与关联状态刷新一致；切换订单或公司不串数据。

### R4 不可编辑原因

- 页面继续解释现有业务锁、财务锁与费用状态限制；锁信息加载失败不放开写入。
- 不把所有不可编辑原因合并成「单条费用已锁定」，不改变已建账费用按财务策略修改的规则。

## 不在本期

- 发票号与开票时间的费用级关联投影、费用级结算／核销金额、创建人持久化。
- 不含税单价、VAT 新定义、通用审核或对账状态机、费用级／方向级新锁、入账月份、费用行佣金比例。
- 跨设备列偏好同步、通用表格配置平台、153 项台账配置重构、全站表格或抽屉改版。
- 新增业务写接口、Schema 迁移、税额计算规则变更、历史数据清空或自动回填。

## 验收标准

| 编号 | 对应需求 | 可观察结果 |
|---|---|---|
| A1 | R1 | 显隐、排序、确定／取消／恢复默认正确；刷新后保持；不同用户／公司隔离，应收应付一致 |
| A2 | R1 | 必填录入字段与操作不丢失；编辑中无法打开列设置，不重置草稿 |
| A3 | R2 | 税额和本币列逐项等于后端字段；零税率显示 0 而非空值；本币代码可见，含税／未税标识准确 |
| A4 | R3 | 相同费用与财务台账的活动账单号、关联账单进度一致；账单取消、核销反转、对冲反转后正确刷新 |
| A5 | R3 | 多笔费用共用账单时清楚标注账单整体进度，不把整账单结清金额重复记为每条费用金额 |
| A6 | R3 | 无财务权限不发送财务请求；失权或跨组织拒绝后清除关联显示，订单费用仍按其自身权限运作 |
| A7 | R3 | 加载失败有错误和重试入口；切换订单／公司及延迟响应不出现前一上下文的账单信息 |
| A8 | R4 | 业务锁、财务锁、已确认、已建账策略及已作废的原写入边界不变；禁用原因可理解 |

## 后续候选与进入条件

- 发票追踪：明确费用行与发票行／账单关系、部分开票、多发票、红冲与取消的展示后另行规划。
- 费用级结算金额：先决定业务是否真正需要费用级分摊；现有核销分配到达账单，禁止前端自行按比例拆分并称作事实。
- 创建人员：覆盖普通新增、补录批准、拆票迁移等真实来源；已有数据不能由订单操作员臆造。
- 跨设备偏好：有明确需求后选择专属订单费用偏好契约与迁移，不覆盖财务台账偏好。
