# 停用状态往返保护设计

## 行为与分层

只在所属领域成功 DTO 的编辑映射边界修正 non-optional 默认值；已建公共 mapper 时复用。区分创建/编辑分支、加载/失败/成功，不引入全局请求层补字段、不机械替换 optional 判断。R1 新专用角色契约不再提交 enabled，仍验证该入口保持停用。组织树和图形同一语义一并修正。

## 影响文件

经 Proto 核对的 admin、partners、enterprise-resources 页内映射与其测试；仅必要的领域公共映射，不修改通用请求拦截器。

## 依赖与并发协作

客商分支在 R1 之后整合；资源页面同 R2 负责人协调，禁止互相覆盖。

## 契约、数据与回退

若修改 Proto，正式生成服务端绑定/OpenAPI/客户端，源与生成物同组审阅。现阶段不预设 Schema 变更；如确有需要，先同步 Ent 与正式迁移方案，禁止自动建表或删除数据。回退通过本子任务提交反向提交，不重置主分支；已写业务数据不自动回写。
