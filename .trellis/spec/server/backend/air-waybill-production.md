# 航空运单制作与PDF

## 1. 适用范围

AE/AI的MAWB、HOUSE模式真实HAWB制作、保存快照预览、下载和打印入口。
DIRECT无HAWB实体或入口，不能为满足输出造空分单。本规范为本组实施约束，
实际结果见任务research，不把模型或版式文件存在当打印验收通过。

正文/模式、共享锁和数值规则继续遵循[航空正文](./air-waybill-content-and-mode.md)、
[空运进口](./air-import-contract.md)。不增加电子签章、航司发送、外部模板市场或通用制单平台。

## 2. 签名与源入口

- 订单内制作路由 `/orders/{air-export|air-import}/:id/awb/{target}`，
  `target`仅允许大写 `MAWB|HAWB`；主单独立制作路由
  `/orders/{kind}/masters/:masterId/awb`，集中routes是入口真相源。
- 从订单进入MAWB先核验本票身份及主单归属，编辑器随后固定真实主单ID与保存快照，
  保存/探测均按主单独立身份执行；不以无关的更晚Order版本充当本次写入基线。
- 既有 `AirMasterWaybill` 新增OUTPUT_ONLY `organization_name_en`，来自真实主单
  `organization_id`对应的公司英文名；不新增数据库列，不从当前工作区或固定公司补造。
  data层经调用方 `Data.client(ctx)` 的客户端读取，service只做投影。
- MAWB保存继续现有Preview→Update及打开时Master.version、预览指纹和原因；
  完整运输input沿打开快照，只明确改 `waybillContent`。
- HAWB保存继续Order普通更新，只提交明确的house正文及Order/Master/Link/House预期基线，
  不夹带一份旧经营字段或运输副本，不改模式、主单、号码或未明确更改的签发状态。
- `awb/pdf/types.ts` 的输出模型持有 `target=MAWB|HAWB,businessType=AE|AI,
  documentId,version,contentHash,masterNo,houseNo?,issuerDisplayName,outputKind,
  organizationId,content`；renderer只消费保存快照，不读取业务API或决定权限。

## 3. 契约

### 真实主体与业务状态

- AE本公司HAWB为 `SELF_ISSUED`，抬头取目标主单真实公司英文名及ID；缺英文名明确阻止输出，
  仍允许维护正文。不能把系统工作区、当前另一公司、固定Roncin名当目标主体。
- MAWB和AI主分单为 `EXTERNAL_ARCHIVE`，印发主体只取该单证已保存 `content.issuedBy`。
  缺失时明确阻止输出，但允许继续登记；不从当前公司、代理或航司自动猜测替换。
- 公司抬头与正文issuedBy是独立事实，不因投影或输出覆盖已保存印字。
  归档页明确“登记资料/归档”，不伪造外部法律条款、签章或本系统办理签发/放货。
- 保存、签发事实、运输进度及输出独立；预览/下载/打开打印不推进单证状态、订单flow或费用。
  已锁/终止票可按读取权限输出保存快照，写入继续遵守原业务门禁。

### 编辑、版本与生命周期

- 每次成功读取严格比对目标ID、实际公司、业务类型、模式和合法版本；
  HAWB还须属于本票/本主单。缺失或错身份不为旧mock放行。
- 制作页固定打开快照及各实体版本，前台15秒与回焦探测，隐藏/非当前页面暂停。
  发现主单/分单/关系/正文/真实主体变化持续提示，保留输入，不借最新版本提交旧稿。
- 保存等待中的新输入、刷新代际、新编辑serial、卸载与公司/目标切换均隔离迟到响应。
  成功只采纳属于本次写入的确切版本及身份；更晚响应不自动覆盖正文或替换编辑基线。
- 预览基于保存快照，未保存内容不能冒称新版本；生成前重读核对快照，失败或冲突不生成
  假新稿。覆盖未保存输入前须确认，取消和失败保留原稿。
- 输出指纹包含单证ID/保存版本/正文hash及规范化印字、真实主体资料、模板修订。
  公司英文名变化不一定推进Master.version，仍必须使旧输出失效。
- 预览iframe、下载和打开打印共用同一usePDF Blob URL；数据/模板变化重建，
  卸载回收旧URL，生成失败可重试。renderer/字体按需加载，普通订单首屏不加载。

### 分区、金额与分页

- 一套A4航空版式覆盖保存正文的全部分区：收发/账号、通知/代理及IATA、印发人、
  路线航班印字、账务/处理/SCI、声明币种、运价表、其他费用、PPD/COLL汇总、
  目的站币种与换算、签发纯日期/地点/签字印字、条款/唛头/货描和备注。
- 声明AMOUNT零值与NVD/NCV/XXX文本、AS ARRANGED未知金额分别表示；
  金额两位、数量/汇率/比例保精度，纯日期不转换时区，输出不反写原始载荷。
- 正文长度和各200行明细按航空现合同完整输出；长party/货描/明细正常续页，
  不裁切、取前N行或缩成不可读小字。页眉页脚仅放有界单号摘要、保存版本和页码，
  长原号码与正文全文仍在可分页正文中保留。
- 同一orders模块内真实共用字体/字符覆盖/字宽工具放中立目录，以最小接口供HBL/AWB使用；
  HBL业务wrapper/四种自签与SI归档语义保留。航空不得深引HBL专属模型或版式。

## 4. 校验与错误矩阵

| 条件 | 结果 |
| --- | --- |
| DIRECT请求HAWB制作或目标不属于本票/主单 | 明确不可用，不造分单或借另一票 |
| 缺对应AE/AI读取/编辑权限或跨公司 | 不读取/不提交；服务端仍真实目标复验 |
| AE自制HAWB缺真实公司英文名，或外部单缺已存issuedBy | 保存可继续，输出明确阻止并说明补齐项 |
| Order/Master/Link/House基线过期或成员被锁 | 原业务409，不部分保存、不推进假预览版本 |
| 保存/重读在途又输入，或切公司/目标/新会话 | 保留新输入，迟到响应不关闭新稿或触发下载 |
| 保存后更晚版本或主体/模板变化 | 旧输出失效并持续提示刷新，不能直接下载旧稿 |
| 字体缺字符、生成失败 | 明确提示/允许重试，不静默缺字或输出空白 |

## 5. 正常、基准与错误案例

- 正常：AE HOUSE保存独立HAWB正文，使用真实公司英文名输出；同票MAWB仍有不同正文/版本。
- 基准：AI DIRECT只有MAWB归档，issuedBy保存外部主体；长地址、200行费用和末行正常续页，
  预览/下载/打开打印同URL，不把归档当办理签发。
- 错误：从当前工作区取英文抬头冒充外部承运人；只检查布局树Text存在就宣布PDF文字完整；
  保存失败却用旧版本号配新输入生成文件。

## 6. 必需验证

- 真实航空wire/主分保存及权限：optional未设、显式零/空、DIRECT无house、主分独立hash版本、
  共享锁/旧版本409、主体公司投影严格归属，源/生成物幂等。
- 前端两目标/双模式/真实AE-AI权限、保存失败与后续版本、在途输入、刷新确认、
  15秒/回焦/隐藏/离页、A→B→A、主体英文名变化及模板变化使旧输出失效。
- 实际PDF渲染后独立提字和逐页看图：普通/极值长文、多行200表、中文、金额/比例、
  声明文本/AS ARRANGED、末行/页码/保存版本及字框边界。布局树和PDF文件头不足以证明字形可见。
- HBL原自签四版和SI外部归档相邻，架构边界及按需font/renderer；生产build后真实同域
  深链、脚本、字体MIME、未知assets404及AWB实际预览。打印入口同Blob验证不冒称物理打印。

## 7. 错误与正确

错误：`issuer = currentOrganization.name`，或日期控件和页面当前输入直接拿来拼PDF。

正确：模型只消费当前目标的真实主体投影与已保存正文，携明确ID/版本/hash；
生成前复验保存快照，三种输出使用同一Blob，长文逐页提字与实图核查。
