# 财务当前公司工作区

## 1. 适用范围
费用、账单、收付、发票、核销、对冲、提成与提成方案，以及建账、开票、收付登记、核销、提成生成/申请/调整和方案名单等业务入口。公司由全局工作区决定，不在页面或弹窗中再选。

## 2. 身份与契约签名
- 唯一公司来源：`useInitialState().initialState.currentUser.currentOrganization`；经营身份复用 `useAccess().canOperateBusiness`，目标归属复用 `canOperateOrganization(id)`。
- 公司ID不属于Form、可恢复查询或用户筛选，不写隐藏字段、不镜像到可变state，不接受预览调用的公司覆盖参数。公司名/本币用认证投影；列表、详情、CSV中的归属展示继续保留。
- `ListFinanceOrganizationOptions`（GET `/api/v1/finance/organization-options`）及其独占类型已退役。共享 `FinanceOrganizationPurpose` 仅保留0、4（收付创建）、9（核销创建），其余原名称/编号reserved；`ListFinanceSettlementPartyOptions` 继续按4/9使用对应动作权限。
- 保留其他业务DTO的 `organizationId`；开票和核销创建由实体鉴权，契约没有该字段时不添加猜测字段。
- 提成方案列表省略重复的「所属公司」列，方案查询、创建、编辑、复制与名单仍固定当前公司并校验来源归属。

## 3. 数据流与校验
列表/候选/导出/预览/提交都使用同一认证公司，先组装业务筛选，最后显式写公司ID。身份未就绪或非公司工作区不发经营请求、不提交；官方列表request返回失败，不把未请求当成功空快照。

固定带入费用、所选账单/资金、编辑/复制/名单的方案属于业务来源，须与当前公司等值。缺归属或外公司来源明确拒绝，不采用来源公司覆盖当前工作区，也不静默改挂来源。

来源选择时保留已验证的记录快照，后续预览/提交仍校验该已选来源；不能只从当前关键字的候选结果find来认定归属，否则搜索其他关键词会误清合法来源。来源切换、关闭或工作区变化时按既有会话边界清理快照和预览。

移除公司表单字段时，同时移除Form依赖、候选启用条件和 `getFieldValue('organizationId')` 读取，禁止保留无法满足的“请先选公司”提示。提成候选必须直接使用认证公司，避免ProFormDependency读取已删除字段后永久禁用。

候选与公司配置并行加载时，信用策略等展示能力在最终选项投影中计算，不能只在queryFn中固化请求发出时的策略。策略迟到后禁用状态必须更新，不改写服务端返回的原始候选或信用规则。

列表仍走官方request/actionRef/onLoad；指标、筛选汇总及当前页导出共享已采纳快照。切公司继续由AppLayout/OrganizationWorkspace的用户+组织key重建，沿用请求取消、QueryClient清理、勾选/弹窗销毁和未保存确认；不另造组织状态机。

## 4. 错误矩阵
| 场景 | 结果 |
| --- | --- |
| 当前公司A，恢复筛选或Form残留公司B | 查询与提交公司仍为A；公司不再作为可编辑/恢复字段 |
| 认证未就绪、系统/部门工作区 | 不发送经营请求，不允许提交 |
| 固定来源或所选实体公司B，当前A | 明确拒绝，不改挂、不自动重试到B |
| 候选/预览失败、保存失败 | 保留输入与dirty，失败不能视作成功 |
| 全局切换取消或失败 | 保持原身份及输入；成功才销毁旧工作区 |
| 旧预览或抬头响应迟到 | 不能覆盖新会话或形成可提交旧目标 |

## 5. 正常、基础与错误场景
正常：公司A打开建账直接取得A费用，预览和创建也属于A。基础：成功取得A的空列表，可展示真实零值。错误：删Select却继续用Form.organizationId加载结算单位，或用固定来源公司覆盖当前公司。

## 6. 必需验证
真实载荷验证六列表、方案、提成导出和子视图当前公司；恢复旧字段不可覆盖；缺身份/非公司不请求；各弹窗正常候选、预览/提交、外公司来源拒绝、失败保留输入、关闭重开及工作区切换隔离。保留金额/幂等/版本与权限相邻用例。后端反射及实际注册验证退役接口缺席、用途4/9及结算单位权限保留；正式生成重跑幂等。

## 7. 错误与正确
```ts
// 错误：筛选或表单控制经营目标。
list({ organizationId: currentCompanyId, ...savedFilters });
create({ organizationId: form.getFieldValue('organizationId') });

// 正确：公司身份校验后，认证公司作为最终请求上下文。
list({ ...businessFilters, organizationId: currentCompanyId });
```
