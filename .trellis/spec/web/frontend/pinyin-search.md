# 全站拼音搜索

## 本地搜索

- 名称搜索统一复用 `web/src/utils/search.ts` 的 `matchesSearch`，支持原文、英文、无声调全拼、分词全拼和拼音首字母；不同字段分别匹配，保留已有精确筛选语义。
- 下拉复用 `SearchableSelect`、`ProFormSearchableSelect` 或 `defaultSelectFilterOption`；不得另写 `label.toLowerCase().includes(input)`。
- 费用候选保留 `nameZh`、`nameEn`、`aliasName` 与费用代码，不能仅用显示标签丢掉可搜索信息；JSX 标签提取可见子文本。
- 远程候选交由服务端按关键字筛选，明确 `filterOption: false`，避免前端过滤掉服务端已匹配的中文结果。
- 主数据客户端模式、组织树、角色与权限、列设置搜索共用同一工具，不发送额外请求或翻页获取全量数据。

## 服务端

- 服务端在 Ent Schema 维护检索字段与 hook，复用 `internal/platform/searchtext.Build`；只读取词组字典，避免可变分词器的隐式初始化和竞态。
- 搜索覆盖既有中文名称的地方同步查询对应检索键；财务名称使用业务快照自身的键，不能只关联当前主档来代替原始显示名称。
- 订单发货人与收货人使用独立检索列，禁止组合名称后导致两个筛选条件交叉命中。
- 完整载荷的批量更新须显式写入对应检索键。部分字段更新走 UpdateOne，由 hook 合并未修改的旧字段；不得让改名、清空或导入覆盖留下旧键。
- Schema、正式迁移、索引及 `BackfillSelectorSearchKeywords` 同组更新；读音算法变更时在正式迁移中清空派生旧键，再由迁移命令重建，不修改业务版本和更新时间。
- 列表、汇总和导出复用同一查询条件，公司范围与权限判定保持在原查询中。

## 验证

至少验证费用实际编辑下拉、全拼与首字母、英文与别名、远程结果不被二次过滤、中文词组读音、已有数据回填、修改/清空/导入后的键更新，以及筛选字段与公司范围隔离。

服务端词组读音与前端 `pinyin-pro` 补充业务词组保持一致（当前为闵行、还箱、还柜）。
利润、账龄与收付报表的原生 SQL 同样查询客户/结算单位检索键，分页与导出共用条件。
