# ADR 0008: 前端模板复用体系 @/components/ui 与满屏流式布局

- 状态：已采纳
- 日期：2026-08-22 主数据模板；2026-08-24 页面容器模板体系成文
- 主题：前端

## 背景

后台页面数量大（订单、财务、主数据、后台管理等），早期各页面自搭骨架：
页头样式、卡片结构、操作栏位置各自为政，还出现过私自定义
`maxWidth: 1440` 水平居中容器的页面，导致同一系统在不同页面呈现两种
宽度策略。重复骨架代码也让 AI 会话每次都要重新理解页面结构。

## 决策

- 公共模板组件统一由
  [../../../web/src/components/ui/](../../../web/src/components/ui/)
  导出，按页面类型选模板：
  - 整页分节表单/详情页：`PageHeaderShell` + `SectionCard` +
    `StickyFooterBar`（吸顶导航、品牌蓝竖标分节卡片、吸底操作栏）；
  - 订单多品类表单：`OrderFormTemplate` 配置式分节，不另造表单骨架；
  - 主数据/通用 CRUD：`MasterDataTemplate`（统计卡 + 筛选 + 分页表格 +
    模态表单）；
  - 表格列表页：ProTable 高密度样式。
- 全站以 `<PageContainer>` 为顶级骨架，布局遵循
  [../../../web/config/defaultSettings.ts](../../../web/config/defaultSettings.ts)
  的 `contentWidth: 'Fluid'` 流式全屏自适应，背景统一 `#f5f7fa`；严禁任何
  页面硬编码 `maxWidth: 1440` 或自定义水平居中外层容器。
- 侧边栏折叠宽度基准 48px、菜单项 36px 居中圆角卡片；折叠态含子级菜单
  Hover 弹出纯白圆角子菜单浮层。
- 视觉基线是「纯白高密度企业级」；2026-09-16 的 Slate 主题 Token 精修
  （`e2a4bd02`）只调整边框、阴影与表格 Token 阶梯，仍在此体系之内。

## 理由

- 企业后台的价值在密度与一致性，不在每页的创造性；模板化让新页面只写
  业务差异。
- 满屏流式由全局设置统一控制，比每页自定 max-width 少一个腐化点；历史上
  的 1440 居中容器正是「局部最优、全局撕裂」的产物。
- 主数据模板与 ADR 0006 的全量/分页二分配套：小数据集走客户端模式，
  大数据集走服务端模式，同一模板组件两种数据策略。

## 后果

- 新页面评审先问「为什么不能用现有模板」；引入无关的大型聚合组件被禁止。
- 模板组件是高风险公共变更，改动需要完整前端检查（见
  [../../../AGENTS.md](../../../AGENTS.md) 分阶段验证）。
- 规范全文见
  [../web/frontend/component-guidelines.md](../web/frontend/component-guidelines.md)。
