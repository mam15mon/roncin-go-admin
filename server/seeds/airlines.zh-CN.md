# 航空公司中文对照数据编制说明

编制日期：2026-11-16。配套底表为仓库当前 `airlines.dat` 与
`server/cmd/sync-airlines/dict.go` 的重点航司补充规则。

## 覆盖与身份

`airlines.zh-CN.csv` 按 IATA 代码排序，逐条覆盖当前解析结果 **988** 条，
中文覆盖率 **100%**。其中 **451** 条 `existing`、**537** 条 `translated`。
本表只补中文名称，不修改代码、英文名称、国家、运单前缀或启停判定。

| 字段 | 含义 |
| --- | --- |
| `iata_code` | 当前解析后的二字母/数字代码，一码一行 |
| `name_en` | 与解析后的英文名称逐字一致，防止代码重用造成身份错配 |
| `name_zh` | 有来源的已有中文名称，或按英文品牌、地名编制的意译、音译 |
| `name_kind` | `existing` 为已有中文；`translated` 为本次编制或修订，非官方标准名 |
| `source_ref` | 既有字典路径、Wikidata 实体链接或编制依据 |

988 是本仓库归档和现有筛选规则的结果，不是全球正在运营航司的数量。
OpenFlights 中既有历史航司、虚拟航司，也有铁路、分销服务等带 IATA 代码的实体；
`Active=Y` 不能证明其在编制日仍在经营。本次保留原始档案边界，未按当前代码
持有人替换历史英文身份，也未把同名或同代码的其他实体合并进来。

## 来源与编制方法

| 来源 | 条数 | 采用方式 |
| --- | ---: | --- |
| 项目重点航司中文词典 | 136 | 完整保留 `server/cmd/sync-airlines/dict.go` 的中文名称，包括国航、东航、南航、美国航空、加拿大航空及主要货运航司；词典同时维护的英文身份、运单前缀等规则保持不变。 |
| [Wikidata](https://www.wikidata.org/) | 315 | 按 P229 IATA 代码及英文标签共同核对；只采用对应代码与英文名一致、无歧义的实体中文标签，逐行保留实体 URL。繁体字转为简体；未凭代码单独认领中文名。结构化数据采用 [CC0](https://www.wikidata.org/wiki/Wikidata:Licensing)。 |
| 本次编制或修订 | 537 | 按英文品牌、地名意译或音译。初始长尾候选由 [Argos Translate en→zh 1.9](https://github.com/argosopentech/argospm-index) 离线模型生成，随后逐项审阅、修订明显误译、纯英文和只有通用航空词的候选；部分 Wikidata 标签经核查不适合直接采用，也归入本类。 |

机器候选并未直接当作行业标准名。例如 `Air Salone` 的“空气沙龙”、
`Aerolitoral` 的“气质”、`VickJet` 的“维基百科”等品牌误译，以及 `Deutsche Bahn`
不能当作银行或航空品牌，均按实体名称重新核对。已有来源也并非天然正确：
`Jet2.com` 的“里尔机场”、`FlyNordic` 的“廉价航空公司”、`Air Japan` 的纯英文
中文标签等没有原样入表；这些修订以 `translated` 标识。

`L`、`N1`、`Zz`、`88` 等原档名称过短，中文仅保留对应读音或字面名称，
不补造公司全称。`All America`、`Regionalia` 等名称保留原品牌及地区含义，
不能将这些条目视为已核实运营资质的现实承运人。

编制名称不声称经过当地航司、民航机构或业务专家逐条审定，长尾音译未必是
行业通行译法。页面继续同时展示原英文和代码，方便业务核对。后续取得可引用
中文来源时直接维护此 CSV 的译名、类别与依据，不更改英文身份迁就中文名称。

模型来自 [Argos 官方模型存储](https://data.argosopentech.com/argospm/v1/translate-en_zh-1_9.argosmodel)，
包 SHA-256 为 `433e7c4f034d87fbe2353161e05f18646d7999452f801a4e1f0378522b9850ab`。
对应 OPUS-MT 模型由 Jörg Tiedemann、Santhosh Thottingal 等提供，包内声明
原模型采用 CC BY 4.0；参见 [OPUS-MT](https://github.com/Helsinki-NLP/Opus-MT)。
模型、Python 包、联网采集及翻译缓存仅用于本次编制，不属于项目运行时依赖。

## 同步与维护

```bash
# 仓库根目录：读取固定归档，完整离线校验，不写库
go -C server run ./cmd/sync-airlines

# 配置 DATABASE_SOURCE 后显式写入，根脚本本身包含 -apply
pnpm run sync:airlines

# 自定义版本须同时提供其完整中文对照；先预览，再显式 -apply
go -C server run ./cmd/sync-airlines -source /path/to/airlines.dat -chinese-source /path/to/airlines.zh-CN.csv
```

日常同步只读取归档与 CSV，不联网抓中文或运行翻译。默认归档缺失会直接报错，
不使用旧缓存或自动下载另一版本；仅显式 `-source URL` 才会下载，并须同时显式
指定配套 `-chinese-source`。换版或修改重点词典后，须按解析集合处理中文表的
新增、撤销和英文更名；不能只替换英文底表。

写库前严格校验表头、UTF-8、代码格式与唯一性、集合覆盖、英文身份、有效中文、
类别和来源。缺行、多行、错版、英文加“航空公司”占位等均明确失败，禁止在线
补译或静默跳过。有数据库配置时再检查同码来源冲突；无数据库配置只可预览，
`-apply` 必须有连接。同步新建与同来源更新都写入中文并刷新全拼、首字母检索键，
重复运行保留 ID，既有单据引用不变。
