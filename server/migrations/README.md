# 数据库迁移

所有环境关闭 Ent 自动迁移，通过服务端内置迁移命令顺序执行本目录中的版本化 SQL。
执行器使用 PostgreSQL advisory lock 防止并发部署；每个文件与迁移记录在同一事务
中提交，并校验已执行文件的 SHA-256，禁止修改历史迁移。

迁移链包含冷启动基础结构和后续增量变更，可从空 PostgreSQL 数据库顺序执行。在
仓库根目录配置 `.env.local` 的 `DATABASE_SOURCE` 后执行：

```bash
pnpm run migrate:server
```

迁移不使用 `IF EXISTS` 或 `IF NOT EXISTS`。数据库结构与预期不一致时会立即失败，
由部署人员核查差异，禁止静默跳过。若历史迁移确需修复以支持空库冷启动，必须在
迁移执行器中显式登记旧文件校验和；兼容范围只能精确到该迁移和该校验和，且必须
同时保留冷启动与未知校验和拒绝测试。
