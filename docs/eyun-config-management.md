# 易云（eyun.hgj.com）配置管理模块 — 功能拆解笔记

> 来源：https://eyun.hgj.com/base/config （配置管理页面）
> 整理日期：2026-08-29
> 用途：roncin-go-admin 复刻参考。所有弹窗均只查看未提交，未改动任何线上数据。

## 0. 页面总体结构

```
配置管理（/base/config）
├── 子标签页（8 个）
│   地址管理 | 备注管理 | 图片管理 | 标签管理 | 收货人管理 | 发货人管理 | 通知人管理 | 业务信息代码管理
├── 每个标签页 = 筛选区(可选) + 操作按钮区 + 可配置列的表格 + 分页
└── 通用组件：行勾选、"当前页全选"、列设置、行内操作(编辑/删除)
```

- **技术栈**：Vue + Element UI（弹窗 `el-dialog` 居中样式 `el-dialog--center`，自定义关闭按钮 `div.close`），下拉支持搜索过滤，省市区三级联动。
- **通用交互**：
  - 未勾选数据点批量操作 → toast 提示「请选择一条或者多条数据」
  - 表格右上角"当前"复选框 = 当前页全选；旁边区域为列显示设置
  - 行内"操作"列固定为 编辑 / 删除
  - 弹窗按钮组合有三种：`取消/确定`、`取消/保存`、仅`确定`

| 联系人 | input | |
| 联系电话 | input | |

- 选中后删除所选标签

### 挂靠对象查证补记（2026-08-29 实测）

- 标签的实际消费方包括**订单、费用和账单**：
  - 海运出口订单列表（`/order/sea_export`）→“批量操作”下拉含“添加标签、删除
    标签”，与锁定、完结、退关等订单批量操作并列。
  - 费用明细（`/cost/detail`）→“批量操作”下拉含“添加标签、删除标签”，与标记
    对账、费用锁定、归档等批量操作并列。
  - 账单管理（`/cost/bill`）→“批量操作”下拉含“添加标签、删除标签”，与核销、
    录入发票号、归档等批量操作并列。
- 勾选订单后弹窗按标签组展示字典标签（组"谛达"：谛达支付、默认、部分核销），
  与本页标签管理维护的是同一份数据；弹窗内另有"新增标签"快捷入口。
- 费用和账单的标签弹窗是否同样按组展示字典、是否提供快捷新增入口，尚未逐项验证。
- 订单和账单的默认表头、默认搜索区未见标签展示或标签筛选；是否存在自定义列或扩展
  筛选未进一步查证。
- 结论：标签管理承担公共字典角色，订单、费用和账单均具备批量添加、删除标签入口。
  自动继承或传播、按标签筛选、企业关联以及不同费用入口间的数据关系均未从竞品界面
  得到验证。

## 5/6/7. 收货人 / 发货人 / 通知人管理

> 三页结构完全相同（同一组件复用，仅弹窗标题不同），列表字段、筛选、按钮一致。

### 列表

- **筛选区**：简称、企业名称、企业代码、企业地址（input）；国家代码、客户、供应商、国外代理（select）
- **按钮**：查询、重置、新增、批量关联、批量导入、展开筛选/收起筛选
- **表头（13 列）**：序号、简称、企业名称、企业代码、企业地址、国家代码、联系电话、页面展示、客户、供应商、国外代理、创建人、操作

### 新增弹窗（标题=收货人/发货人/通知人，取消 / 确定）

| 字段 | 控件 | 说明 |
|---|---|---|
| 简称 | input | |
| 企业名称 | input | |
| 企业代码 | input | 校验：需含"+"、+号前后不能含空格 |
| 企业地址 | textarea | |
| 国家代码 | select | 默认 CN中国 |
| 联系人（联系电话） | input | |
| AEO代码 | input | 没有AEO资质的留空 |
| 页面展示 | 只读 textarea（默认"CN"）+ "自定义"复选框 | 带入到页面中展示的内容，勾选自定义可快捷填写发货人信息 |

### 批量关联（下拉菜单，需先勾选行）

- 关联客户 / 关联供应商 / 关联国外代理（无"关联地址类型"），弹窗结构同地址管理

### 批量导入 → 弹窗"导入收货人"

1. 选择模板（select，默认"默认模板"）
2. 下载模板（链接）
3. 上传文件（拖拽或点击上传）
4. 导入结果反馈：合计 N 条 / 导入成功 N 条 + 错误信息表（列 / 异常原因）
5. 重复数据处理：提示「下面的公司抬头重复，是否在原有公司详情中添加模板中信息(基础信息数据将被覆盖)」+ 表格（公司抬头 / 代码 / 社会统一信用代码）

### 其它按钮

- **查询**：按筛选条件过滤表格
- **重置**：清空筛选条件
- **展开筛选 / 收起筛选**：切换筛选区展开状态

## 9. 复刻建议

1. **统一页面模板**：标签页 + 筛选区 + 按钮区 + 可配置列表格 + 分页 + 弹窗表单，8 个模块共用。
2. **独立表单只有 6 种**：地址、备注、图片、标签（新建/编辑标签组）、收发通知人（三合一）、业务代码。
3. **批量关联做成通用组件**：入参为关联维度列表（客户/供应商/国外代理/地址类型），弹窗内是可搜索的公司/字典选择。
4. **批量导入做成通用组件**：模板选择 + 下载 + 上传 + 结果反馈 + 重复覆盖确认。
5. **字典/枚举**：备注类型 14 种、地址类型 3 种、省市区三级 + 海外、国家代码、标签组，建议后台可配置。
6. 省市区联动数据源：34 省级行政区 + 海外。
