# 提成管理增强计划

## 1. 文档目的

本文用于指导 `roncin-go-admin` 提成管理三项增强的设计、实施与验收：

1. **导出提成**：按当前筛选条件导出提成列表。
2. **CNY 折算展示**：提成生成时快照 CNY 口径金额，列表双列展示。
3. **提成归属日期**：从核销单派生不可变的提成归属日期，支持按月份筛选与归档。

本文以 2026-08-30 的仓库代码为基线，并引用同日对易云竞品 `/company/commission`
的实测结论。本文是实施计划，不代表功能已经完成。

## 2. 竞品参照（2026-08-30 实测）

易云提成管理具备：列表"导出提成"按钮；新增提成页的订单选择表同时展示本位币与
CNY 各五组金额（应收/应付/利润/实收/结余）；"提成时间"作为独立字段与筛选条件。

采纳边界：

- **采纳**：导出能力、CNY 双口径展示、"提成时间"独立维度。
- **不采纳**：易云将 CNY 金额作为展示时实时折算的做法（推测，未验证其实现）。
  本项目提成金额全部为不可变快照，CNY 口径同样必须在生成时一次性固化。
- **不采纳**：易云的"提成时间"由用户手工选择；本项目提成锚定核销单，归属日期
  从 `verification_date` 派生，不由用户填写。

## 3. 当前实现基线

1. **提成模型已完整**：`FinanceCommission` 锚定 `verification_id`，状态机
   DRAFT→CONFIRMED→PAID/CANCELLED，规则名/版本/口径/人员归属均为 immutable
   快照，`source_fingerprint` 防来源漂移；金额字段（realized_revenue、
   allocated_cost、realized_profit、commission_base_amount、commission_amount）
   均为本位币（`base_currency`），无 CNY 字段，无独立归属日期。
2. **核销单已具备汇率折算体系**：`FinanceVerification` 保存 `currency`、
   `exchange_rate`、`exchange_rate_source`、`exchange_rate_date`、`base_amount`、
   `verification_date`（全部 immutable）。提成现用的本位币金额已经过核销时折算。
3. **汇率解析能力已存在**：`ExchangeRateUsecase.Resolve(organizationID,
   rateType, direction, currency, dateCandidates)` 可按日期解析组织汇率。
4. **导出先例**：`ExportPartners` 为 JSON RPC（`GET /api/v1/partners/export`，
   独立权限 `business.partner.export`），响应返回结构化条目，由前端生成 CSV
   （带 BOM）。提成导出沿用同一形态，不引入异步导出中心。
5. **筛选现状**：`CommissionFilter` 仅有 keyword/status/分页，无日期维度。
6. **权限现状**：提成读取 `system.finance.commission.read`，生成与规则维护
   `system.finance.commission.manage`；无导出权限。

## 4. 方案决策

### 4.1 已确认决策

- **CNY 快照时机**：提成生成（预览通过、生成草稿）时，按核销单的
  `exchange_rate_date` 解析 `base_currency → CNY` 汇率并快照；`base_currency`
  为 CNY 时汇率记 1、来源记 `BASE_CURRENCY`。金额、汇率、汇率日期、来源全部
  immutable，确认与支付阶段不再变动。
- **归属日期派生**：`commission_date = verification.verification_date`，生成时
  快照，immutable；不支持用户修改，作废后重新生成的提成按新核销单重新派生。
- **展示口径**：列表增加"CNY 提成"列与详情金额区 CNY 行；本位币列保持现状，
  不做实时折算。
- **导出形态**：JSON RPC + 前端 CSV（BOM），沿用 `ExportPartners` 先例；导出条
  件与列表筛选一致并叠加日期区间。

### 4.2 阶段 0 待确认

1. **汇率缺失策略**：生成时若无法解析该币种该日的 CNY 汇率——推荐**阻止生成
   并明确报错**（与"禁止静默兜底"一致）；备选为允许生成但 CNY 留空并标注"未折
   算"，需产品确认。
2. **明细行是否折算**：第一版仅主单级 CNY 快照；`FinanceCommissionLine` 是否
   需要 CNY 明细，待出现逐单 CNY 报表需求再扩展。
3. **导出上限**：建议单次导出上限 10000 行，超出明确报错提示缩小筛选范围；
   上限值由产品确认。

## 5. 数据模型变更

`FinanceCommission` 新增字段（全部 immutable）：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `commission_date` | date(10) | 归属日期，派生自核销单 verification_date |
| `cny_exchange_rate` | numeric(18,8) | 生成时按核销汇率日期解析的 base→CNY 汇率；本位币为 CNY 时为 1 |
| `cny_exchange_rate_source` | enum | SYSTEM / BASE_CURRENCY，沿用核销枚举口径 |
| `cny_exchange_rate_date` | date(10) | 使用的汇率日期 |
| `cny_commission_amount` | numeric(28,8) | commission_amount 的 CNY 快照 |
| `cny_realized_profit` | numeric(28,8) | realized_profit 的 CNY 快照（报表用，可选阶段 0 裁剪） |

存量数据（如有）：本地开发数据不迁移，字段按默认值（CNY 金额为 0、汇率日期空）
保留；首次生产基线直接包含最终结构。

索引：`organization_id + commission_date`（按月筛选）。

## 6. 后端契约

```http
GET /api/v1/finance/commissions/export   // 权限 system.finance.commission.export
```

请求复用列表筛选（keyword、status、commission_date_from/to），响应返回
`CommissionExportItem` 列表：提成编号、状态、核销编号、归属日期、提成员工、考
核角色、规则名称、计提口径、比例、本位币币种、本位币提成、CNY 提成、原始/有效
提成、创建时间。

`ListCommissions` 增加筛选参数并返回新字段；`GetCommission`/预览响应同步返回
CNY 快照与归属日期。预览响应增加将使用的 CNY 汇率与汇率日期，让用户在生成前看
到折算依据。

## 7. 权限

新增 `system.finance.commission.export`（依赖 `system.finance.commission.read`），
目录归入"费用管理 · 提成"，与 `business.partner.export` 先例对齐。权限键同步生
成前端常量。

## 8. 前端

- 列表：新增"归属月份"日期区间筛选、"CNY 提成"列（本位币非 CNY 时展示）、
  "导出提成"按钮（按导出权限显隐，复用 CSV 生成与 BOM 处理）。
- 生成弹窗预览区：展示 CNY 汇率与汇率日期；预览通过后生成草稿。
- 详情：金额区增加 CNY 行与汇率信息。

## 9. 审计与事务

CNY 快照与归属日期在生成草稿的同一事务内写入，随既有
`finance.commission.*` 审计动作记录 `cny.exchange_rate`、`cny.rate_date` 详情；
导出为只读操作不写审计。

## 10. 分阶段实施

- **阶段 0**：确认 4.2 三项决策；核对汇率 Resolve 在 base→CNY 方向的 rateType
  取值。
- **阶段 1**：模型与迁移（新字段 + 索引），生成事务写入 CNY 快照与归属日期，
  预览返回汇率依据。提交：`feat: 增加提成 CNY 快照与归属日期`。
- **阶段 2**：导出 RPC + 权限 + 列表筛选与前端导出按钮。提交：
  `feat: 增加提成导出`。
- **阶段 3**：前端 CNY 列、详情展示、预览汇率展示与测试补齐。提交：
  `feat: 增加提成 CNY 展示`。

测试至少覆盖：汇率缺失时按确认策略行为、本位币为 CNY 时汇率恒为 1、
commission_date 等于核销日期、导出权限拒绝与行数上限、既有生成链路不回归。

## 11. 非目标

- 展示时实时折算或可切换多币种视图。
- 提成明细行级 CNY 折算。
- 异步导出中心与 Excel（xlsx）格式。
- 归属日期手工调整与跨期重算。

## 12. 风险与控制

| 风险 | 控制措施 |
| --- | --- |
| 生成时汇率缺失导致提成无法出具 | 按阶段 0 策略显式报错，不写零汇率快照 |
| CNY 快照与确认/支付金额口径漂移 | 快照 immutable，后续状态只改状态字段 |
| 导出被当作数据导出通道滥用 | 独立权限 + 行数上限 + 仅导出当前筛选结果 |
| 归属日期与核销日期不一致 | 生成时派生快照并在测试中断言相等 |

## 13. 完成定义

- 生成草稿的提成包含 CNY 快照（金额、汇率、汇率日期、来源）与归属日期，且与
  核销日期一致；确认、支付不改变这些字段。
- 列表可按归属月份筛选并展示 CNY 提成列；预览可见折算依据。
- 拥有导出权限的用户可按当前筛选导出 CSV（含 BOM），无权限用户不可见入口。
- 迁移链、后端测试、前端测试、类型检查与构建全部通过。
